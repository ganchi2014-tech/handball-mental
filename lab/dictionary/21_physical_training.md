# フィジカルトレーニング辞書（ハンドボール特化）

> **この章を開く場面**：体づくり（筋力・ジャンプ・スピード・持久力）の考え方と種目を知りたいとき。量や回数は、部の計画と自分の体に合わせて決める。
>
> バックプレーヤーに特化した体力強化の全体像。技術練習（19_drills.md）と並行して行う。
> 出典：EHF公式資料・DHB 運動能力づくりの考え方 2024・IHF・PMC査読論文・アスペター・スポーツ医学誌

## 【なぜフィジカルが必要か】バックプレーヤーの試合負荷データ

```
研究（PMC 2023, Physical Demands during Official Competitions in Elite Handball）

バックプレーヤーの1試合平均走行距離：約4.96 km
  ※ウィング（4.23 km）・ポスト（3.91 km）より多く、全ポジション中最長

速い走り（ある速度以上）の距離：センターバック平均 243.2 m/試合
スプリント距離（全力疾走＝高速走行よりさらに速い走り）：センターバック平均 62.0 m/試合
試合中の心拍数：HRmax（最大心拍数=その人が出せる心拍数の上限）の85〜90%で推移（ほぼ全力に近い強度）

→ バックプレーヤーは全ポジション中、最も体力資源を消費するポジション。
→ 投擲能力（シュート速度）と跳躍能力の両立が最重要要件。
```

## 【A】主要筋群と役割（なぜその筋肉か）

### A-1. 上半身

| 筋群（日本語） | ハンドボールとの関連 |
|---|---|
| 回旋筋腱板（棘上筋・棘下筋・小円筋・肩甲下筋） | シュート動作の減速制御。多数の投擲に耐える肩の土台 |
| 三角筋 | オーバーハンドスローの推進力 |
| 前鋸筋 | スロー時の肩甲骨安定化 |
| 僧帽筋下部 | 投球肩予防に不可欠 |
| 広背筋 | 腕の加速・減速の両方に関与 |
| 腹斜筋 | 体幹回旋→サイドアームシュートの動力源 |
| 体幹（インナーマッスル） | 下半身の爆発力を上半身へ伝達する連結部 |

### A-2. 下半身

| 筋群（日本語） | ハンドボールとの関連 |
|---|---|
| 大臀筋・中臀筋 | 踏み切り・方向転換・ランジの主動力 |
| 大腿四頭筋 | ジャンプシュートの離地力 |
| ハムストリングス | スプリント加速・着地衝撃吸収。ノルディックで損傷が減ると言われる〔未確認〕 |
| 腸腰筋 | 跳躍後の着地コントロール・走フォーム |
| 内転筋群 | 横方向の急停止・サイドステップ安定 |
| 下腿三頭筋 | 踏み切り・スタートダッシュ |

## 【B】筋力トレーニング

> **読み方**：ここにあるのはドイツ協会などの資料にある方法と数字の紹介で、部の計画ではない。
> やるか・どの方法で・どの強さと回数でやるかは自分で決める。目安として使う。
> 方法の種類：自重（腕立て・スクワット・懸垂・体幹など。器具なしでできる）／バーベルやダンベル／ジャンプ系／メディシンボール。

### 基本方針

```
研究エビデンス：
ベンチプレス1RM（最大1回挙上重量）とシュート速度の相関係数 r = .637（1.0に近いほど強い関係。0.6超は「かなり強い関係」で、偶然ではないと統計的に確認された）
→ 上半身の筋力とシュート速度には関係があると言われる（関係があることと、鍛えれば必ず速くなることは別）

教材に載っている強度の目安（高重量は正しいフォームを身につけてから、指導者のいる所で行う。部の計画ではない）：
  最大筋力期 → 85〜95% 1RM
  爆発力期（爆発力）   → 60〜80% 1RM（最大重量の6〜8割。軽めにして最大速度で素早く挙げ、速さを鍛える）
```

### ハンドボール特化種目

```
ケーブルウッドチョップ
  → 斜め上から斜め下へ。腹斜筋・体幹回旋。シュート動作と直結。

サイドランジ
  → 内転筋・大臀筋。横方向の急停止動作に直結。

ゴブレットスクワット
  → 体幹と下肢の協調。方向転換前の準備姿勢。

ラテラルバンドウォーク（ゴムバンドを付けて横に歩く）
  → 中臀筋強化。膝・股関節外側安定化。足首捻挫予防にも。

ワンアームランドマインプレス
  → 片手プレス・回旋安定性。実際の投擲動作に近い。
```

## 【C】ジャンプトレーニング

### 研究エビデンス

```
研究（PMC 2023。ユース女子ハンドボール・10週間・週2回）：
  SJ（しゃがんだ姿勢で静止してから跳ぶ＝反動なし跳び）・CMJ（一度しゃがむ反動を使って跳ぶ＝反動あり跳び）・立ち幅跳びが有意改善

メタアナリシス（エリートハンドボール選手）：
  SJ 改善率：4.5〜13.9%
  CMJ 改善率：5.7〜11.4%

複合プログラム（筋力＋プライオメトリクス 12週間）：
  SJ +6.1%、CMJ +3.8%、連続40回ジャンプ +6.8%
```

### テスト種目

| テスト名 | 略称 | 内容 |
|---|---|---|
| スクワットジャンプ | SJ | しゃがんだ姿勢で止まってから跳ぶ垂直跳び（反動なし） |
| 反動をつけた垂直跳び | CMJ | 立った姿勢からしゃがんで、すぐ跳ぶ（筋肉の反動を使う） |
| 腕を振った垂直跳び | CMJA | 上と同じで、腕の振りも使う |
| 立ち幅跳び | SLJ | 両足で前へ跳ぶ |
| ドロップジャンプ | DJ | 台から降りて、着いたらすぐ跳ぶ |

### プライオメトリクス種目（レベル別）

```
基礎レベル：
  ボックスジャンプ / スクワットジャンプ / 幅跳び / スキッピング

中級レベル：
  ドロップジャンプ / ラテラルバウンド（横跳び） / 片脚CMJ / ディプスジャンプ

上級レベル：
  ボール操作を含む反応跳躍 / ジャンプ中のメディシンボール投げ / ハードルホップ
```

**注：** CMJ（しゃがむ反動を使う跳び＝遅いSSC）はSJ（縮む力だけで跳ぶ＝同心収縮のみ）より高いトレーニング効果を得やすい

## 【D】スピード・アジリティ（すばやい方向転換）

### ハンドボール特化型ドリル

**Tテスト**
```
設定：コーンをT字型に配置（縦10m・横各5m）
実施：前方10mダッシュ → 左5mサイドシャッフル → 右10mシャッフル → 左5mシャッフル → バックペダルでスタートへ
基準：男性 9.5秒未満 = 優秀〔未確認〕
```

**プロアジリティ（5m・10m・5mの折り返し走）**
```
設定：3点コーン（各4.5m）
実施：中央スタート → 右4.5m → 左9m → 中央4.5m
目的：短距離での最大加速・急停止・切り返し
```

**コート特化型スプリント**
```
シャトルスプリント：6mライン〜センター往復（2×15m）
バックプレーヤー特化：25m往復ダッシュ（長い距離より短距離が試合に即している）
バック＆フォース：ゴール〜センターの前後ダッシュ繰り返し
```

**横跳び（スケートのように左右へ跳ぶ）**
```
横方向への単脚跳躍繰り返し
→ サイドステップの爆発的パワー。コートカバーに直結。
```

## 【E】持久力トレーニング

### ハンドボールの持久力特性

```
試合時間：60分（前後半各30分）
試合中平均心拍数：HRmax の85〜90%
バックプレーヤー：高強度活動の割合が全ポジション中最多

有酸素能力の目標値（男子エリート）：VO₂max（最大酸素摂取量＝1分間に体重1kgあたり取り込める酸素量で持久力の指標）50〜60 ml/kg/min
```

### HIIT プロトコル（例3種類）

**タイプ A：4×4分（ハンドボール最多使用）**
```
内容：4分間 HRmax の90〜95%強度 → 4分アクティブリカバリー（60〜65%）
セット：4セット
頻度：研究では週2回を8〜12週間続けた例が多い（部の計画ではない）
根拠：ハンドボール選手のVO₂max改善に最も高いエビデンス（系統的レビュー 2024）
```

**タイプ B：短インターバル（EHF推奨・試合特異性が高い）**
```
内容：10秒間 最大速度の95%で走行 → 20秒リカバリー
セット：2セット × 22本
特徴：ハンドボールの動作パターン（短い爆発＋短い回復）に最も近い
```

**タイプ C：長インターバル（有酸素容量構築）**
```
内容：3分間 最大速度の85% → 3分リカバリー
セット：5セット
特徴：有酸素ベースの構築に有効
```

**スモールサイドゲーム**
```
少人数・狭コートでのゲーム形式
効果：持久力・技術・戦術を同時に鍛えられる
研究：SSGグループはTテスト・シュート速度・Yo-Yoテストで有意改善
実践：スペイン・スカンジナビアのクラブで有酸素トレーニングの主要代替手段として使用
```

**Yo-Yo インターミッテントリカバリーテスト**
```
正式名：Yo-Yo Intermittent Recovery Test Level 1
内容：20mシャトルランを漸増速度で実施。各ラン後10秒アクティブリカバリー
用途：ハンドボール選手の持久力評価の標準テスト
```

## 【F】年齢別の考え方（ドイツ連盟の教材から）

### 長期育成の5段階（ドイツ連盟の教材から）

| 段階 | 対象年齢 | 主な内容 |
|---|---|---|
| 1 | ～12歳 | 多様な動作・楽しさ優先 |
| 2 | 12〜14歳 | 協調性・自体重・体幹安定 |
| 3 | 14〜16歳 | 外部負荷導入（砂袋・ケトルベル） |
| 4 | 16〜18歳 | バーベル筋力・爆発力の系統的発達 |
| 5 | 19歳〜 | 競技特化・個人特化 |

### 高校生（16〜18歳 / アウフバウトレーニング第2段階）の具体的指針

```
ドイツの教材の目安：週2〜3回、1回30〜45分（部の計画ではない。回数や時間は部の予定に合わせる）
毎練習前にアスレチックウォームアップ（15分）
バーベル筋力トレーニングの本格導入
爆発力と最大筋力の両方を計画的に鍛える
固有受容感覚トレーニング（バランスボード等）の導入

ノルウェー研究（PMC 2021・15〜18歳・205名）による警告：
  この研究では、週6回以上の練習で負荷がかかりすぎるおそれが示された
  週間傷害発生率 53%、重篤な怪我の割合 38%
  → RPEスケール（自分のきつさを0〜10で点数化する主観的運動強度の指標）を使用し、週sRPE（1回の練習のきつさ点数×練習時間を1週間ぶん合計した値。単位AU）を1,000〜1,400 AU以内に抑える
```

## 【G】時期ごとの計画（ピリオダイゼーション）

> 資料にある考え方の紹介。「試合の前後で負荷を変える」という見方を知るためのもので、部の予定表ではない。

### シーズン区分と重点

| 期間 | 主な目標 | 内容 |
|---|---|---|
| プレシーズン（大会前の準備の時期） | 体力の土台づくり | 量を多めにした筋力づくり・持久力の土台 |
| インシーズン（大会が続く時期） | 試合での動きを保つ | 筋力を落とさない程度の筋力トレーニング・少人数ゲームでの持久力づくり |
| オフシーズン（大会がない時期） | 回復と作り直し | 軽く動いて回復・持久力の土台 |

### 試合からの日数で見た並べ方の例

> 教材に載っている例。部の計画ではない。何をいつやるかは、部の予定と体の状態で決める。

| いつ | 内容 | きつさ |
|---|---|---|
| 試合の翌日 | 軽く動いて回復 | 低 |
| 試合の2日後 | 筋力トレーニング（重め） | 高 |
| 試合の3日後 | 技術・戦術の練習と少人数ゲーム | 中 |
| 次の試合の3日前 | 筋力トレーニング（量を少なく、落とさない程度） | 中 |
| 次の試合の2日前 | スピード・すばやい方向転換 | 中 |
| 次の試合の前日 | 軽い技術練習・体を起こす | 低 |
| 試合当日 | 試合 | 最高 |

## 【H】ケガ予防（くわしくは25章）

ケガの予防は `25_injury_prevention.md` にまとめてある（肩＝【C】、膝＝【D】、足首＝【E】、成長期の負荷＝【F】、復帰の進め方＝【I】）。体づくりの面から見た要点だけ：

- ハンドボールのケガは膝・足首に多く、バックプレーヤーは投げる側の肩に負担がたまりやすい。
- 肩は、外へひねる力と肩甲骨まわりを鍛える種目を入れる。
- 太もも裏・お尻・片脚で立つ力は、膝と足首を守る土台になる。
- 痛みがあるときは続けない。指導者に伝え、必要なら医療機関で診てもらう。
