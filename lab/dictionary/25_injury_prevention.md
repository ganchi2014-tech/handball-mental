## 【A】バックプレーヤーの傷害リスク

```
【最重要リスク】肩の過負荷傷害
  肩の過負荷傷害報告者の89%がバックコートプレーヤー
  成人プロ選手で投球肩の過負荷傷害有病率：26〜28%

原因：
  1試合で多数の投擲動作の繰り返し
  外旋筋力低下
  肩甲骨機能異常
  間接的な接触でのケガ（相手と直接ぶつからず、接触をよけた拍子などに起こるケガ）：31.5%

【第2リスク】膝の過負荷傷害（膝蓋腱炎）
  ジャンプ・加速・減速の繰り返しによる腱の過負荷反応
  12〜14歳の男子に多い

【第3リスク】足関節捻挫
  再受傷率：40〜70%（非常に高い）→ 二次予防が重要
```

## 【B】ウォームアッププログラム

### エビデンス

```
15件の研究のメタ解析（PMC 2022）：
  体系的なウォームアッププログラムで傷害発生率36%削減

ノルウェー（skadefri.no）のプログラム：
  急性膝・足関節傷害を最大50%削減可能
```

### B-1. 4段階のウォームアップ（ドイツ連盟の教材から）

**4段階で体を温める。元の教材の設定は、練習前に15〜20分。**

**1段目：関節を大きく動かす**
```
関節を自分で大きく動かして、動く範囲を広げる
例：股関節・背中（胸のあたり）・肩甲骨を大きく動かす運動
```

**2段目：筋肉を目覚めさせる**
```
筋肉をほぐし、血の流れをよくして、力が入りやすい状態にする
例：お尻・太もも裏・体幹に力を入れる運動
```

**3段目：すばやい動きを入れる**
```
全力に近い速さの動きを入れて、体がすばやく動ける状態にする
例：短いダッシュ・ジャンプ・方向転換
```

**4段目：ハンドボールの動きに入る**
```
試合で使う動きそのもので仕上げる
例：シュートの動き・ステップ・ポジションごとのプレー
```

### B-2. VBG「ハンドボールの4×4」

**VBG（ドイツ職業保険組合）開発のハンドボール特化型予防トレーニング。**

```
4つの柱：
1. 体を安定させる・強くする
2. 関節を動かす・柔らかくする
3. 肩を思いどおりに動かす
4. 脚の軸をまっすぐ保つ・着地のしかた

実施方法：各領域から3〜4種目を選んでウォームアップに組み込む
収録：100種目以上。器材少なく実施可能。
```

### B-3. ノルウェーの「怪我のないハンドボール」プログラム

```
NHF（ノルウェーハンドボール連盟）が推奨する包括的プログラム
肩・膝・足関節にフォーカス（ハンドボール傷害の50%超がこの3部位）
ウォームアップ15〜20分：ボール使用可、バランスボード活用
元のプログラムの設定：週3回以上（部でやる回数は部の計画で決める）
URL：https://www.skadefri.no/idretter/handball/

## 【C】肩傷害予防（バックプレーヤー最重要）

### C-1. OSTRC（オスロスポーツ外傷研究センター）ショルダーコントロールプログラム

**オスロスポーツ外傷研究センター（ノルウェー）開発。最大のエビデンスを持つ肩予防プログラム。**

```
エビデンス（RCT・45チーム660名のエリートハンドボール選手）：
  介入群の肩傷害有病率：17%
  対照群：23%
  → 28%削減

研究での設定：週3回・10分・ウォームアップに組み込む（部でやる回数は部の計画で決める）
```

**5つの目的と具体的エクササイズ（チューブ/エラスティックバンド使用）：**

**① 肩を外へひねる力をつける**

```
エクササイズA（90°外転位）：
  立って、腕を真横に肩の高さまで上げ、肘を90°に曲げる
  チューブを、腕を外へひねる方向に引く
  引くとき1秒、戻すとき2秒（ゆっくり戻す）
  3セット×10回、セット間休憩30秒

エクササイズB（腕を体につけた形）：
  腕を体の横につけ、肘を90°に曲げる
  チューブを、腕を外へひねる方向に引く
  3セット×10回
```

**② 肩甲骨まわりを思いどおりに動かす**
```
Yレイズ（前かがみやうつ伏せで、腕をYの字に上げる）：肩甲骨の下のあたりと、肩の奥の筋肉を使う
ゴムバンドで腕を外へひねる運動：軽い負荷で回数を多く
```

**③ 肩を内へひねる動きの硬さをとる**
```
肩の後ろ側を伸ばすストレッチ：30秒×3回
横向きに寝て、下になった腕を内へ倒すストレッチ（スリーパーストレッチ）
```

**④ 運動連鎖活性化**
```
体幹安定化
腰椎・骨盤のコントロールが肩への過負荷を軽減
```

**⑤ 胸椎モビリティ**
```
胸椎回旋ストレッチ
フォームローラーを使った胸椎伸展
→ 胸椎の硬さ＝肩の代償運動増加につながる
```

**注意：** 外旋を行うエクセントリック（筋肉を引き伸ばしながら力を出す）エクササイズだけを8週間やるのでは効果が不十分。多要素プログラムが推奨。

### C-2. 肩予防の追加ポイント

```
筋不均衡の修正：投球側の一側性過負荷由来
肩甲骨スタビライゼーション
制御された動作パターン
→ 投球負荷への段階的適応
```

## 【D】膝傷害予防

### D-1. ACL（前十字靭帯）傷害予防

```
ACL = 前十字靭帯（膝の中にある靭帯）

リスクプロファイル：
  女性ハンドボール選手（15〜19歳）が特に高リスク
  カットプレー・着地・急停止の際に発生
  ACL再建術後2年以内の再受傷率：20〜30%

ノルウェー女子ハンドボールの実績：
  神経筋トレーニングの導入でACL傷害50%削減を達成
```

**ニーコントロール（膝を守るプログラム。スウェーデンで作られ、研究で効果が確かめられている）：**

```
6種の主要エクササイズ（各A〜D難易度レベル）：
1. 片脚スクワット
2. お尻上げ（仰向けで骨盤を持ち上げる）
3. 両脚スクワット
4. プランク（うつ伏せで体を一直線に保つ）
5. ランジ
6. ジャンプと着地

進め方：元のプログラムでは、慣れたら1段ずつ難しくする
元のプログラムの設定：週3回（部でやる回数は部の計画で決める）
```

**追加エクササイズ：**
```
ノルディックハムストリング（太もも裏を、伸ばされながら耐える形で鍛える）
片脚スクワット
プランク（形を変えて）
バランスボード練習
```

### D-2. 膝蓋腱炎（ジャンパー膝）予防

```
ジャンパー膝（膝のお皿の下の腱が痛むケガ）

予防・管理エクササイズ：
  重めの負荷をゆっくり動かすトレーニング（HSR）
  傾斜台でのスクワット（ゆっくり下ろす動きを重く見る）：HSRと並んでよく使われる方法の一つ（痛みがあるときは医療機関の指示に従う）

プログレッション：
  レッグプレス → スクワット → ハックスクワット → 足を前後に開いたスクワット → 座って膝を伸ばす運動

研究（思春期ハンドボール選手でのRCT）：
  機能的高負荷エクサイズで競技シーズン中の腱痛有病率を有意に削減
```

## 【E】足関節捻挫予防

```
ハンドボール最多の急性傷害（22.2%）
再受傷率：40〜70%（非常に高い）→ 一度捻挫したら二次予防が必須
```

### 予防の3本柱

**① バランス・神経筋トレーニング**
```
バランスボード・ウォブルボード使用
片脚立ち・ジャンプ着地訓練
再発リスクを約50%削減
→ 捻挫歴ありの選手に最も有効
```

**② テーピング・サポーター**
```
捻挫歴あり選手：テーピング・ブレーシングで再発リスク50〜70%削減
捻挫歴なし選手への予防効果は限定的
テープ vs. ブレース：同等の効果

バディテープ：
  非弾性スポーツテープで隣接指同士を固定
  締め付けすぎず、緩くない張力で
  指の捻挫・脱臼予防にも活用
```

**③ 着地技術**
```
VBG 4×4の「脚軸制御と着地技術」が直接対応
着地時の膝内側への崩れを防ぐ意識
→ 足関節・膝の両方を守る
```

## 【F】成長期（ユース・高校生）の過負荷傷害予防

### F-1. 成長期特有のリスク

**オスグッド・シュラッター病**
```
脛骨粗面の成長板への反復牽引ストレス
発症年齢：男子10〜15歳・女子8〜13歳
発症率：スポーツ選手の13〜17%
症状：脛骨上部の痛み・腫れ

予防：
  急激なトレーニング量増加を避ける（10%ルール参照）
  大腿四頭筋のストレッチ強化
  症状が出たら負荷を下げる
```

**セーバー病**
```
踵骨骨端炎（成長板）
好発年齢：8〜12歳（女子が早い傾向）
症状：踵の痛み

予防：
  踵への反復衝撃を管理
  下腿三頭筋のストレッチ
  クッション性の高い靴・インソール
```

### F-2. 予防戦略（成長期共通）

```
① 10%ルール：週あたり練習量の増加を10%以内に抑える（目安。根拠には議論がある）
② スポーツ多様化：複数スポーツへの参加推奨（特に12歳以下）
   → 特定動作の反復過負荷を防ぐ
③ 休息期の設定：競技シーズン後に積極的休息期
④ 栄養管理：カルシウム・ビタミンD不足は骨ストレス傷害リスクを増加
⑤ 痛みのシグナルを無視しない：
   「痛みをこらえてプレー」は悪化・慢性化・ストレス骨折を招く

トレーニング負荷モニタリング：
  RPE（主観的運動強度）で週・月単位の練習量を管理
  目安（`21_physical_training.md` も見る）：1週間のsRPE（その日の練習のきつさ感覚×練習時間（分）を週で合計した値）を1,000〜1,400AU（その合計値の単位）以内に収める
```

## 【G】クールダウンとリカバリー

### G-1. クールダウン（練習・試合後5〜15分）

```
静的ストレッチング：
  ※練習前ウォームアップには不適。練習・試合後に実施。
  推奨：各ストレッチ2回×75秒
  対象：大腿四頭筋・ハムストリングス・股関節・肩・胸椎

フォームローリング：
  20〜30秒間、硬い部位で一時停止
  筋の硬直軽減、可動域改善
  筋痛の軽減にも有効
```

### G-2. リカバリー手段（エビデンスレベル別）

**研究で効果がよく確かめられているもの：**

```
氷水に浸かる（アイスバス）：
  水温10〜15℃
  10〜15分間浸水（3分間の分割でも可）
  効果：筋痛軽減・腫脹抑制（筋力トレーニングの直後に毎回使うと、筋力の伸びを弱めることがあると言われる。連戦の合間など回復を急ぐ場面向き）

着圧ウェア（コンプレッションウェア）：
  疲れの元になる物を流しやすくする、腫れをおさえる

フォームローラーでほぐす：
  筋肉の張りをやわらげる、動く範囲を広げる
```

**その他：**
```
積極的回復：
  軽い有酸素運動（サイクリング・スイミング）
  血流改善・代謝老廃物除去

空気で脚を締めたりゆるめたりする機器（専用の機器で脚を空気の圧により周期的に締めつけ、血流を促す回復手段）：
  多競技大会での有効性を示すエビデンスあり
```

## 【H】睡眠・栄養・水分補給

### H-1. 睡眠

```
推奨睡眠時間（思春期アスリート）：1夜8〜10時間
  ※現実平均：約6.3時間（目標と大きくかけ離れている）

研究エビデンス：
  8時間未満で傷害リスク1.7倍上昇
  平日に8時間以上眠った選手：新たなケガの起こりやすさが61%低かった

睡眠不足の影響：
  コルチゾール増加 → 筋タンパク分解促進
  グリコーゲン補充障害
  炎症性サイトカイン上昇 → 結合組織の脆弱化
  運動性疼痛・疲労の主観的増大
```

### H-2. 栄養

```
炭水化物：
  推奨量：6〜10g/体重kg/日（練習1〜3時間/日の場合）
  最重要エネルギー源。認知・身体パフォーマンスの制限因子

タンパク質：
  推奨量：1.2〜2.0g/体重kg/日
  繰り返しの筋損傷回復に必須

脂質：
  総エネルギーの25〜30%以内

タイミング：
  試合・練習後2時間以内：高糖質＋良質タンパク質の食事
  → グリコーゲン回復・筋タンパク合成促進
```

### H-3. 水分補給

```
試合後：失った体重の150%相当を2時間以内に補給
  例：体重1kg減少 → 1.5L補給
電解質（特にナトリウム）の補充が重要
試合中：糖質と電解質の入った飲料（濃さは6〜8%程度が目安と言われる。濃すぎるとお腹に負担がかかることがある。環境・個人差に応じて調整）
```

## 【I】復帰の進め方（復帰プロトコル）

### 戻るまでの5つの段階

```
1. 治りはじめ：痛みは軽くなるが、中はまだ治っていない
2. 動きを取り戻す：ケガをした側の筋力は急に落ちる（治った後も、反対側と比べて2〜3割の差が残ることがある）
3. ハンドボールの動きを取り戻す
4. チーム練習に戻る
5. 試合に戻る

大事なこと：痛みが消えた ≠ 治った
  急いで戻ると、同じ所をまたケガしやすい
  いまどの段階か、次へ進んでよいかは、医療機関と指導者に確かめる
```

### 部位別の目安

| 傷害 | 復帰目安 | 注意事項 |
|---|---|---|
| 肩（SLAP修復後＝肩関節の受け皿のふち（関節唇）の損傷を縫い直す手術の後） | 12〜16週 | 段階的なスローイングプログラムが必須 |
| ACL再建後 | **平均7.7ヶ月** | 若年選手ほど再受傷リスク高（20〜30%/2年） |
| 足関節捻挫 | 重症度による | 戻った後も、サポーターとバランスの練習を続ける |
| 膝蓋腱炎 | 症状管理次第 | 痛みがないことを確認しながら段階的に負荷増加 |

## じゃんけん構造（ケガ予防）

```
トレーニング量を増やす
  → 傷害リスクが上がる（特に成長期）
  → 体系的ウォームアップで36〜50%削減できる
  → ウォームアップをしない
  → 傷害リスクが戻る

肩を酷使する（投球反復）
  → 外旋筋力低下・肩甲骨機能異常
  → OSTRC（オスロスポーツ外傷研究センター）プログラムで28%削減できる
  → 睡眠・栄養が不足
  → 組織回復が遅れて傷害悪化

捻挫した
  → 再受傷率40〜70%（高い）
  → バランストレーニング＋ブレーシングで50〜70%削減
  → 急いで復帰する
  → 再受傷する

→ 絶対安全はない。リスク管理の継続が唯一の答え。
