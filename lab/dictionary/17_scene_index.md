## 【L】特定状況の即時対応リファレンス

### 自分がボールを持って固まったとき

```
Q: 何をすればいい？
A: 見るものの例（順番は場面で変わる）：
  ① シュート打てる距離・角度か → YES：シュートフェイントを入れて打つ or ドライブ
  ② ポストへのパスコースあるか → YES：即パス
  ③ 隣にはたけるか → YES：はたく
  ④ どれもなし → コントロールドリブルで時間を作る → 再び①へ
```

### DFがめちゃくちゃ詰めてきたとき

```
Q: 何をすればいい？
A:
  ① 接触してきたら廻旋フェイント
  ② シュートフェイントで一旦距離を作る
  ③ ポストに即逃がす
  ④ 無理に抜こうとせず、ボールを守って接触を受ける（フリースローで組み立て直す）
```

### GKのタイプが分からないとき

```
Q: 試合序盤、どうする？
A:
  最初の3〜5本は「普通に打って」GKの反応を観察
  → 動いた → 先読み型 → 早打ち or バックハンドフェイクへ
  → 動かなかった → コース絞り型 → 引きつけて角度変化へ
  → 状況で変わる → 混合型 → 場面ごとに使い分け
```

### ミスをしてしまった直後

```
Q: 次のプレーへどう切り替える？
A:
  → やり方は2通り：すぐ切り替える／短く振り返って次の手を入れ替える（`18_mental.md`）
  → すぐ切り替える場合：3秒以内に次へ
  → 自分への声かけ：「次は○○する」と自分に言う
  → 自分の合図：握手・深呼吸・特定のジェスチャーで集中再起動
  → 次のプレーで小さな成功を作る（できた実感 = 達成感）→ 自信が戻る
詳細は `18_mental.md`
```
