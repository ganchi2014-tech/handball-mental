## コートの見方（全図共通）

```
          相手ゴール方向
  ┌─────────────────────────────┐
  │  LW    LL    C    RL    RW  │ ← バック/ウィング層（9m付近）
  │              PV             │ ← ポスト（6m付近）
  │  ─────────── 6m線 ──────── │
  │       D₁ D₂ D₃ D₄ D₅ D₆   │ ← 守備陣
  │            [ GK ]           │
  │         ┌────────┐          │
  │         │  GOAL  │          │
  └─────────────────────────────┘

ポジション略称
  LW = 左ウィング      RW = 右ウィング
  LL = 左バック        RL = 右バック
  C  = センターバック  PV = ポスト
  GK = ゴールキーパー  D  = ディフェンス
```

## パート 1：サインシステム（どう伝えるか）

### 1-1. サインを出すタイミング

```
笛の合図で再開するスローは、笛から3秒以内に投げる（笛なしで再開できるフリースローもある）
            ↑この「準備の3秒間」がサインプレーの設定ウィンドウ

・センター（C）が背を向けてからサインを出す
  → DFから手元が見えない
  → 「誰に何を渡すか」を悟られにくい

・笛直後にすぐサインを出せるほど速攻できる
```

---

### 1-2. コードワード方式（言葉でサイン）

**ドイツ流・コードワード命名文化：**

ハンドボールでは「プレーの動き」ではなく「名前（コードワード）」で呼ぶ。名前自体に意味はなく、チームが記憶しやすいものを選ぶ。

| コードワード例 | 命名の由来 |
|---|---|
| **ポーランド式** | ポーランド遠征中の試合で使ったプレー、と言われる |
| **ユーゴ** | ユーゴスラビア発祥のクロスプレー（最古の定番の1つ） |
| **Russe / Däne** | 各国名をランダムに命名 |
| **Döner / Kölsch / Baguette** | 食べ物シリーズ（日常語で覚えやすい） |
| **Max / Werner / Oma / Mama** | 人の名前シリーズ |
| **Hawaii / Jamaica / Kuba** | 島・地名シリーズ |

> **サインプレーの目的として紹介される考え方：**  
> 全プレーの目的はDFを動かすこと。バックプレーヤーが勢いのある良い位置でボールを受けられれば、それで十分。

---

### 1-3. 数字方式（シンプル番号制）

```
「1 左！」 → プレー1番、左方向
「2 右！」 → プレー2番、右方向
「Neun！」       → プレー9番（固定で覚えておく）
「2 Jamaica！」  → プレー2番、島名が方向を示す（右）
```
- 数字＋島名 or 方向の組み合わせで意味が確定するシステム
- ユースや高校チームに向いたシンプル方式

---

### 1-4. 手のサイン（ベンチ→コート）

※下は方式の例。自分たちのサインと意味はチームで決める。

| サイン | 意味 |
|---|---|
| 指を1〜4本立てる | プレー番号を示す |
| 手のひらを上に向ける | 攻撃プレー実行 |
| 手のひらを下に向ける | DF変更指示 |
| 腕をクロスさせる | クロスプレー系 |
| 左右を指差す | そのサイドへ展開 |
| 交代選手が伝達 | コーチが控え選手に伝え→交代で入りながら伝達 |

> **交代でサインを運ぶ：**  
> 重要なフリースローの前にコーチがわざと選手交代を行い、コートに入る選手が（ベンチで聞いたサインを）口頭で仲間に伝える。ルール上も認められた合法な手段で、効果的。

---

### 1-5. ポジション位置がサインになる

選手の**立ち位置そのもの**がサインになるシステム：

```
例）ポスト（PV）が6m線の左側に立つ → 「左展開」
例）LLが極端に開いた位置に立つ → 「ウィングプレー」
例）CBが9mより前に出る → 「速攻型フリースロー」
```
- DFに言葉を聞かれるリスクなし
- 事前に「この立ち位置＝このプレー」とチームで合意が必要

---

### 1-6. コート内キャプテンのサイン

※下は方式の例。自分たちのサインと意味はチームで決める。

| サイン | 意味 |
|---|---|
| 拳を握り上げる | プレーAを実行 |
| 手のひらを開く | プレーBを実行 |
| 特定の選手を指差す | その選手が起点（トリガー） |
| 頭を叩く | フリーフロー（即興・自由判断） |
| 口頭でコードワード | 最多使用、センターが叫ぶ |

## パート 2：フリースロー（9m）からのサインプレー

### ─ 基礎プレー群 ─

### P01：シンプルクロス

```
実行前：
  LW  [LL]  C  [RL]  RW
             ↑
             C がボールを持つ

実行中（矢印は走る方向）：
  LW    ←LL       RL→    RW
            ↘   ↙
           （交差点）
             C がどちらか良い方へパス
```

| 項目 | 内容 |
|---|---|
| 独語名 | シンプルクロス |
| プレーヤー数 | 2名（LL+RL） |
| ポイント | LLとRLが同時にお互いに向かって走り交差。DFの「誰が誰を守るか」を混乱させる |
| DFの反応 | ①スイッチ（交代して守る）②ついていく（衝突リスク）③追跡不能でフリー |
| パス先 | 交差後に有利な位置にいる方を選ぶ |

---

### P02：クロス＋スクリーン

```
実行前：
  LW  LL  C  RL  RW
              PV（6m中央付近に立つ）

実行中：
  PV が D₃ のマーク前に立って「スクリーン設置」
       →→→→RL が PV の体を使って走り込む
  C がRLへパス（スクリーンを抜けた瞬間に）
```

| 項目 | 内容 |
|---|---|
| 独語名 | クロス mit ブロック |
| 別名 | Deckungssuche（守備のスクリーン探し） |
| ポイント | ポストがDFにスクリーンをかけてRLを解放する |
| 決定的タイミング | RLがスクリーンを抜けた**瞬間**にパス → 勢いのあるシュートへ |

---

### P03：ピック＆ロール

```
①  RL → C にパス（RL がCに寄る）
②  RL は C のDF（D₄）にスクリーンを設置
③  C がスクリーンを利用してドライブ
④  RL は「ロール」→ 6m方向に反転しポスト位置へ

リードアフター：
  ※番号は見る順の例。DFの反応で入れ替わる
  C がシュート    ← 第1選択
  C → PV へパス  ← 第2選択
  C → ロールしたRL（第2ポスト）← 第3選択
```

| 項目 | 内容 |
|---|---|
| バスケットボールとの比較 | ほぼ同じ概念。ハンドボールでは「Deckungssuche」（DFを探す動き）と呼ぶ |
| 選手要件 | Cに1on1突破力、RLはロール後のポジション取りが必要 |

---

### P04：ユーゴ（クロスで始める形）

```
ユーゴ 左：
  C → LL へパス
  LL が左方向に1on1ドライブ
  C が LL の元ポジションへ移動（空いた中央を埋める）

ユーゴ 左 クロス：
  C → LL へパス
  RL が C の後ろをクロス（空のクロス）
  LL：1on1 or クロスしたRLへパス
  → RL が中央でフリーの状態を作る
```

| 項目 | 内容 |
|---|---|
| 独語分類 | きっかけの動き（起動プレー） |
| 最大の強み | DFが「クロスに反応」するだけで中央にスペースが生まれる |
| バリエーション | ユーゴ 右 / ユーゴ 右 クロス（右版も同様に使用） |

---

### P05：ポーランド式

```
タイムアウト明け等に使用された「中央混乱」プレー

  LW  LL  [C]  RL  RW
           ↓（Cがドライブ起点）
  LLとRLが逆方向にクロス（空のクロス）
  Cが勢いのある良いポジションへ移動する
  DFが「混乱している中央」でパスを受けてシュート
```

| 項目 | 内容 |
|---|---|
| 命名 | 「ポーランド遠征で使ったプレー」が由来と言われる |
| 目的 | 「バックプレーヤーが勢いを持って良い位置でボールを受けること」 |
| 広まり | ドイツの代表からクラブへ広まったと言われる |

---

### ─ クロス応用群 ─

### P06：ロング（左／右）＝遅らせるクロス

```
「遅れたクロス」— 同時ではなくパスのタイミングで交差を起こす

① C → LL へ加速パス
② LL は一瞬ためる（遅延）
③ RL が LL 前を横切る（クロス）
④ LL → クロスしたRL へパス
   RLが右サイドへ走りこみシュート体勢
⑤ RWは幅を取り続けてウィングDFを釘付け
```

---

### P07：空クロス（ボールを渡さないクロス）

```
「Leer」= 空（ボールなしのクロス）

① C がボールを持つ
② LL と RL が互いの方向へ走る（クロス）
③ LL は「空でクロス」— ボールを受けない
④ C → RL（中央へ切り込む RL へパス）
⑤ 中央が空いた場所でRLが攻める
```
- DFが「ボールのないクロス」に釣られて動いた隙を突く

---

### P08：3人クロス

```
3人が連続クロス

① C と LL がクロス（C左・LL中）
② LL（中央に来た）と RL がクロス
③ C が中間ポジションへ移動
④ PV が前衛DFにスクリーン
⑤ 3つのクロスでDF3名が同時に担当変更→混乱
```

| 利点 | DFに3回連続のスイッチ判断を強いる |
|---|---|
| 難点 | 選手間の完璧なタイミング共有が必要 |

---

### P09：ドッペル（2回入れ替わる）

```
① C が LL 前を通り左へ（1回目クロス）
② LL が中央位置に移動
③ LW → LL（中央）へパス
④ PV がギャップに入る
⑤ C は2回目のロール → 有利なシュートポジションへ
```

---

### P10：ヴィボルグ（弧を描いて位置を取り直す）

```
（デンマーク・ヴィボー HKにちなんだ命名）

① C → LL（右中間）へ加速パス
② C が弧を描いて元LLのポジションへ（バランシング）
③ LL → LW へパス
④ LW → C へパス（C が前へ出てくる）
⑤ 最終アクション：シュート / 突破 / クロス継続
```

---

### P11：ゾルベルグ（4人で回る）

```
（北欧風命名。4人ローテーション）

① C と LL がクロス（1回目）
② LL と RL がクロス（2回目）
③ C がバランシング（3回目のトリガー）
④ RL と C がクロス（4回目 → 完全な4人循環）
⑤ PV が前衛DFに対してスクリーン
```

---

### P12：マクデブルク

```
（SCマクデブルクにちなんだ命名）

① LW-LL-C の三重交換（ダブルエクスチェンジ）
② RL がクロス
③ PV がDFのギャップへポジション
④ C が左バックポジションへ移動
⑤ 最終パス先：最もオープンなプレーヤー
```

---

### P13：ロール

```
「Rolle」= ロール（転がり）

通常版：
① C と PV がクロス
② PV → RL へパス
③ PV が再び6m位置へ落ちる（ロール）
④ バックプレーヤーは外側から圧力を維持

「Raus（外）」バリエーション：
① 同じ起点だがCが左へ落ちる
② LL が RL からパスを受ける
③ Cが第2ポストオプションに
```

---

### P14：切り替え（バックがポストへ移る）

```
サイドへ移る形：
① LL → C へパス
② LL が対角線上に6mへダッシュ（第2ポストになる）
③ C → RL へパス
④ RL が LL の走りが生んだギャップに入る
⑤ PV が中央DFにスクリーン

中央へ移る形：
① C → LL（中央方向）へパス
② LL → RL（開いた方向）へパス
③ PV が中央DFをブロック
④ RL → C へ戻す（C が中央へ帰還）
```

### ─ 特技・個人技系 ─

### P15：ケンパトリック（空中パス→シュート）

```
         ┌────────┐
         │  GOAL  │ ← 相手ゴール
         └────────┘
              ↑
         B（ジャンプ中）← 空中でキャッチ → シュート
              ↑
           A（パス） ← 6m内またはその付近で待機

・A がボールを持ってスタンバイ
・B が弧を描いてダッシュ → ジャンプ
・B のジャンプの頂点で A がパス
・B は空中でキャッチ → 着地前にシュート
・Bが6mに入る前にシュートを放てば適法
```

| 項目 | 内容 |
|---|---|
| 命名 | ベルンハルト・ケンパ（独、1920-2017）。1954年3月24日に初使用 |
| 有名な使用例 | 2007年世界選手権準決勝・独vs仏（延長）でドイツが炸裂させた |
| ビーチハンドボール | ダブルポイント（2点）になるトリックゴール扱い |
| バックラインから | 走り込みながらジャンプするシューターへのパスでGKをリセットさせない |

---

### P16：ダイビングポスト（ダイブシュート）

```
・PV が6m前に立つ
・C またはバックがフリースローを受ける
・C が鋭いパスを PV の走りに合わせて出す
・PV が1〜2歩踏み込みながらダイブ（前傾倒）
・体が6m内に入りながら空中でキャッチ → シュート
・着地前にボールを放せば合法
```

| 難易度 | ★★★★☆ — PVの勇気と体の柔軟性が必要 |
|---|---|
| なぜ有効 | 低い角度・予測不能の軌道。GKがセービングポジションを取る前にシュートが来る |

---

### P17：CSSR変形（ウィングへのスレッドパス）

```
（1970年代チェコスロバキア発祥）

① C がフリースロー or オープンパス → RL へ
② C（またはPV）が D₁と D₂の間のギャップに走り込む（ボールなし）
③ RL が C のギャップ通過前にパス
④ C がパスを受けてスレッドパス → カットしてくる LW へ
⑤ LW が角度のあるシュート

最適条件：
  LW が左利きであれば角度が有利
  ウィングDFが開いたまま → C が直接シュート
```

---

### P18：ダブルスクリーン

```
① C → RL → C → LL と素早くパス回し
② パスが回る間に PV と C（再配置）が
   D₂と D₃に対してダブルスクリーンを設置
③ LL がパスを受けた瞬間
   D₂と D₃がスクリーンに阻まれてクローズできない
④ LL が無人でシュート

配置図：
       D₂         D₃
       |           |
      PV₁        PV₂   ← スクリーン
  LL（ボール保持） → シュート
```

---

### P19：ダイアゴナル（対角線カット）

```
① C がボールを持ちスタンバイ
② LL が左バックから右センターギャップへ対角線ダッシュ
③ LL が D₃ を横切った瞬間に C がパス
④ LL が勢いに乗ってシュート体勢
```

---

### P20：ウェーブ（波状攻撃）

```
  LW → LL → C → RL → RW（左から右へ素早いパス回し）
  ↑パス後の各プレーヤーはゴール方向へダッシュ

・ボールが右に動く間、各選手が内側へ波のように押し寄せる
・右端（RW or RL）がシュート or PV へ縦パス
・折り返し波：右→左でも使用可
```

| 目的 | DFを横方向に引き伸ばしてバック線のスペースを作る |
|---|---|

---

### P21：ワンクロス・ツーストレート（日本でよく使われると言われる〔未確認〕）

```
① RL が斜め前方にカット → C の前でボールを受ける
② RL が縦方向にドライブ（DFを引きつける）
③ LL と C が RL のドライブに合わせてパラレルダッシュ
④ LL が RL からクロスパスを受け → 縦突進
⑤ C がLL の走りと並走 → LL → C へパス
⑥ C がシュート or 空いた PV or ウィングへ

もし第1段が封じられたら：
  RL/LL/C が反対サイドへポジション移動
  LW がスペース確保
  LL と RL が新サイドのギャップを攻撃
```

| 採用チーム | 日本の代表チームでよく使われると言われる〔未確認〕 |
|---|---|
| 強み | DFに「クロスを追うか縦を追うか」の二択を強いる |

### ─ フリースロー速攻系 ─

### P22：クイックフリースロー（早打ち）

```
笛が鳴った瞬間、DFが整列していないことを利用

① 笛直後に C がすぐボールを持つ
② 後退中のDFが3m離れていないことを確認
③ ウィングが既に前を走っている
④ 即座にロングパス or 直接シュート（3秒以内）

※3m離れていないDFがいてもすぐ笛を吹くわけではないのでリスク計算が必要
```

## パート 3：GKスローからのプレー

### P23：GK→ウィングのロングパス速攻

```
  GK がボールをセーブ or デッドボールを受け取る
    ↓（0.5秒以内に判断）
  RW or LW はすでにダッシュ済みでDFの前に出ている
    ↓
  GK → ウィングへロングスロー（頭上を越えて放る）
  ウィングは走りながら受けてそのままシュート
```

| 成立条件 | ウィングが相手DFより前にいること |
|---|---|
| 失敗原因 | GKの判断が遅い、ウィングが戻っていた、パスが短い |

---

### P24：クイックスローオフ（失点直後にすぐ始める）

```
相手がゴールを決めた → 自チームがスローオフ権

通常：選手が揃ってからスローオフ（遅い）

クイックスローオフ：
① GK が即座にボールを拾い上げる
② センタースローオフ位置の C に素早くパス
③ C は中央ライン（1.5m範囲内）でタッチしてすぐスローオフ
④ 相手DFが守備に戻り切れていない状態で攻撃開始

歴史：TBV Lemgo（2002-03シーズン）・THWキール（2001-02）が多用し大会を席巻
```

| IHFルール | スローオフゾーンは中央から1.5m以内。選手はラインを踏めばOK（乗り越え不要） |
|---|---|
| 効果 | 相手が「まだ守備を整えていない」数秒の隙を利用して数的有利を作る |

## サインを意図的に裏切る：予期違反の認知科学

> **この節でやること**：決めた形を何回か見せておいてから、同じ入りで違う終わり方をする。相手が「次もこう来る」と構えた分だけ、反応が遅れる。
> 下は、その理由のくわしい説明（読み物）。急ぐときは読まなくてよい。

### なぜ「サイン通りに動かない」ことが効果を持つのか

サインプレーは「動作を伝える手段」だが、高度なレベルでは**あえてサイン通りに動かない**ことが戦術的な武器になる。その根拠は認知神経科学の「予測的符号化」にある。

---

### 予測的符号化の仕組み

```
DFの脳内モデル：
  「このサインが出た → このプレーが来る」
           ↓
  DFは「見たパターンの続き」を予測して身体を準備する

  → DFの運動準備は「予測された動作」に合わせて先行している
```

研究（ScienceDirect / PMC）によれば、スポーツのだます動きは以下のメカニズムで機能する：

- DFの脳は、相手の動作の初期フェーズから「結果」を予測し、モーター応答を先行させる
- 予測が裏切られると「予測誤差（Prediction Error＝脳の予想と現実のズレ）」が発生し、parietal cortex（頭頂葉＝空間や動きを処理する脳の部位）からventral premotor cortex（腹側運動前野＝動作を準備する脳の部位）へフィードバック（修正の信号）が生じる
- このエラー修正プロセスの間、DFは正しい応答ができない「空白時間」が生まれる

---

### 予期違反が生む時間的空白

| フェーズ | 時間目安 | 説明 |
|---|---|---|
| 予測の生成 | —（先行） | DFが「このサイン→このプレー」を予期してモーター準備 |
| 予測誤差の検出 | 〜150ms | BA6 negativity（脳の運動前野＝BA6で起こる電気的反応）；目で見た情報を体の動きの指令に変換する処理が始まる |
| エラー修正処理 | 150〜350ms | Ne/ERN（error-related negativity＝間違いに気づいたとき脳に現れる反応）が発生し、動きを修正し直す |
| 新しい応答の生成 | 〜200ms以上 | 予測を書き換えて正しい動作が出るまでの総所要時間 |

> ⚠️確認推奨：100〜200msという数字はvisuomotor transformation（BA6）の研究から引用。「ハンドボールのサイン違反に特化した計測値」は現時点で学術的に確認できていない。スポーツ文脈の総所要時間はより長い可能性がある。

**実戦的意味：** サインを呼んで「動かない（または逆に動く）」だけで、DFが動きを直すまでのわずかな間（0.2秒前後と言われる〔未確認〕）、アタッカーは前に出やすくなる。

---

### ダブルブラフの設計

「読まれているサインをあえて呼ぶ」ダブルブラフには2つの構造がある：

```
【第1段：フェイクコール】
  サイン「ポーランド式！」→ 実際は「ポーランド式」を実行しない
  DFが「ポーランド式」の準備 → 予測誤差 → 空白時間
  → 逆サイドまたは別プレーで攻める

【第2段：真のダブルブラフ】
  前提：相手チームが「ポーランド式と言っても実行しない」と学習済み
  → 今度は「ポーランド式！」と言って本当にポーランド式を実行
  DFが「どうせ逆だ」と思って待つ → 予測誤差（逆方向）
  → 本来のポーランド式がフリーになる
```

この2段構造が成立するには「過去の試合でフェイクコールの実績を積む」ことが前提になる。試合序盤でのフェイクコールは後半への「仕込み」として機能する。

---

### 欺き動作の3つの運動学的手法（学術的確認）

スポーツの欺き動作研究（PMC5449506）では、以下の3手法が確認されている：

1. **誇張された動的手がかり** — 「行く」と見せかける大きな予備動作
2. **アプローチ角度の変更** — 走路の方向を途中で変える
3. **誤誘導姿勢** — 上体・頭・視線を逆方向に向ける

ハンドボールのフェイクコールはこれらの身体的欺きとは異なる「**記号的欺き**」だが、DFがサインに基づいてモーター準備を行う以上、同じ予測誤差メカニズムが作動する。

## サインが読まれたときのメタ戦術

> **この節でやること**：サインを出した方向に相手が先に動く場面が2回続いたら、読まれていると考える。まずサインを変える。それでも読まれるときの手は3つ：同じサインから逆へ動く／サインなしで攻める／読まれている動きをわざと見せて相手を寄せ、空いた所を使う。どれを使うかは、相手がどこまで読んでいるかを見て選ぶ（使える手はチームで先にそろえておく）。
> 下は、その理由のくわしい説明（読み物）。急ぐときは読まなくてよい。

### 「サインが読まれる」とはどういう状態か

```
正常状態：
  ATK がサインを出す → DFは知らない → ATK が有利

読まれた状態：
  ATK がサインを出す → DFが内容を知っている → 事前にポジションを取られる
  → サインが「ATKに対して不利なサイン」に変わる
```

サインが継続的に読まれている場合、「サインを変える」のが第1反応だが、それだけではない。より高次の選択肢がある。

---

### 高次メタゲームの3層構造

```
レベル1（基本）：サインを変える
  → 相手が新しいサインを覚えるまでの時間を稼ぐ
  → 限界：スカウティングが精密な相手にはすぐに再読される

レベル2（逆用）：「読まれている前提」でサインを使う
  → DFが動いた方向の逆を攻める（読まれた事実を利用）
  → サインが「DFを動かすためのツール」として機能

レベル3（メタコミット）：手を見せて相手の反応を固定させる
  → DFが「あのサインが来たら○○する」と決定済み
  → ATKはその反応をトリガーとして次の行動を設計できる
```

---

### ゲーム理論的コミットメント：見せることで相手を縛る

ゲーム理論では、以下の構造が成立する：

```
コミットメントの条件：
  1. 観察可能（相手が見て認識できる）
  2. 不可逆性（撤回できない、または撤回コストが高い）

ハンドボールのサインが「読まれた」後：
  ATKがサインAを呼ぶ → DFは「Aが来る」と確信してポジションを取る
                         = DFの行動がコミット（固定）される
  → ATK は「DFがAに対応した後の空白」を使う行動Bを実行できる
```

**実例設計：**

```
① 試合前半でサインAを3回実行 → DFがAを学習
② 後半でサインAを呼ぶ → DFがAへコミット（移動開始）
③ AではなくBを実行 → DFがコミット解除できない0.2秒以上を使う
```

この戦術が機能するには「前半に誠実にAを実行して信頼関係を作る」という逆説的な前提が必要になる。

### 「同じサインを3回連続で呼ぶ」戦術のリスクと効果

| 試行回数 | DFの状態 | ATKの効果 |
|---|---|---|
| **1回目** | 反応遅い（初見） | サイン通りに動けば成功しやすい |
| **2回目** | 学習中・注意高まる | DF修正が入り、成功率が下がる場合がある |
| **3回目** | 「また来る」と予期 → 過剰準備 | ① DFが過剰反応する隙を突く ② フェイクコールとして使う |
| **4回目以降** | 完全に読まれた状態 | 同じプレーでの突破はほぼ不可能。別プレーへの切り替え必須 |

> 研究（PMC：バスケットボールのヘッドフェイク研究）では「フェイクの頻度が上がると欺きの効果が薄れる」ことが確認されている。これはハンドボールのサインフェイクにも同様に適用される。

**リスク：** 3回連続で同じプレーを呼ぶと、DFの「予期」が確定して逆に4回目の同サインが完全封殺されるリスクがある。

**効果：** 意図的に「相手の予期を固定させる」ためのセットアップとして3回連続呼びを使い、4回目に全く別のサインへ切り替えることで最大の予測誤差を生む。

### フリーフローへの切り替えとその判断基準

```
フリーフロー（即興）への移行判断：

条件A：「DFがサインを読んでいる」と試合中に判断できたとき
  → 2回以上、サインを出した方向に事前ポジションを取られたとき

条件B：「DFが陣形を整えるのが遅い」とき
  → フリースロー直後にDFが3m離れていない、速攻に近い状況

条件C：「1on1で勝ち目がある」とき
  → DFの体勢・位置を確認して即興ドライブを選択

移行時のシグナル（各国コーチングで使われる形態）：
  頭を叩く（この章パート1-6より）→「フリーフロー！」の合図
  コードワードなしで動き出す → それ自体がフリーフローの合図
```

### ノルウェーのアプローチ：「反応の自動化」

ノルウェーの「Triggerahandling（起動動作）システム」（この章パート7-5）では、サインが読まれることへの対策として以下のアプローチを取る：

```
サインを出す → 相手が読む
       ↓（ノルウェーの対応）
サインではなく「トリガー動作」に切り替える
= 選手Aの動きが自動的に選手Bの動きを引き起こす

→ 相手は「言葉のサイン」を読んでも意味がない
  なぜなら実際のトリガーは「選手の初期動作」だから
```

「考えずにプレーするほうが良いプレーができる」という考え方は、この「サインに頼らない反射的判断」の文化的背景を示す。⚠️確認推奨：この解釈はインタビューの趣旨を戦術的に解釈したものであり、原文は個人の技術哲学として述べられたもの。

### フランスの実践：パターンの逐次変化

フランス女子の分析（大西論文）では「パターン6」として「DFが読み始めたらパスのタイミング変化で対応」が記録されている。これは本質的に「サインのデコード（読み解き）を遅延させる」メタ戦術であり、以下の構造を持つ：

```
フランスの逐次変化モデル：
  同じ動き（外見上） → タイミングだけを変える
  → DFは「また同じだ」と予期 → しかし来るタイミングが違う
  → 予測は正しいが「いつ」が外れる → 反応が遅れる

効果：動作の種類を変えなくても、タイミングの変化だけで予期違反が作れる
```

### メタ戦術のじゃんけん構造

```
ATK：サイン通りに動く
  ↑ 勝てる         ↓ 負ける（読まれた）

ATK：フェイクコール（逆を動く）
  ↑ 勝てる         ↓ 負ける（相手もフェイクを予期）

ATK：フリーフロー（サインなし）
  ↑ 勝てる         ↓ 負ける（個人技で劣る場合）

ATK：コミットメント戦略（読まれる動作を使ってDFを固定）
  ↑ 勝てる（高次）   ↓ 負ける（実行が複雑でエラーが出る）
```

サインプレーとメタ戦術は、本システムの根底にある「じゃんけん構造」（絶対最強なし）をそのまま体現している。DFとATKがお互いの予測の予測を予測し合うスパイラルが生まれ、最終的には「相手が今どのレベルで読んでいるか」の文脈判断が全てを決める。
