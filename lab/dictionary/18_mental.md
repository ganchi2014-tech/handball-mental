# メンタルマネジメント・自己診断

> **この章を開く場面**：緊張する、ミスを引きずる、終盤に焦る、自信が持てない、といった心の面で困ったとき。
>
> 試合中の不安・緊張・ミス後の立て直し。ノルウェー語のメンタル5概念を核に構成。
>
> **この章の読み方**：心の整え方は人によって合う・合わないがある。ここにあるのは「方法の種類」で、正解ではない。
> 部のメンタルトレーニングの枠は「最適な緊張感は人によって違う（覚醒型・落ち着き型・間の型）。自分に合った方法で向き合う」。
> 出どころの書き方：〔教材〕＝ノルウェー協会などの教材／〔まとめ〕＝AIが一般的な方法を整理したもの／〔未確認〕＝根拠を確かめられていないもの。

## 緊張との向き合い方

部のメンタルトレーニングの枠：最適な緊張感は人によって違う（覚醒型・落ち着き型・間の型）。自分に合った方法で向き合う。

緊張しているときにできること〔まとめ〕（どれが合うかは人によって違う。自分の最適な緊張感に近づくほうを選ぶ）：

| 向き | 方法の例 | 起きること |
|---|---|---|
| 落ち着かせる | 深く吐く呼吸を数回 | 副交感神経（体をリラックスさせる神経）が働き心拍数が下がる。高ぶっているほうが動ける人は、下げすぎると動きが鈍る |
| 上げる | 声を出す・速い足踏みやジャンプ・テンポの速い曲 | 体と気持ちが起きる。上がりすぎると視野が狭くなる |
| 間を取る | 決まった動作を一つ挟む（自分の合図） | 緊張の強さは変えずに、いつもの状態に戻る合図になる |

試合の前にできる準備（イメージ・自分の合図）は、この章の「試合前のメンタル準備」にある。試合中にミスをした後の立て直しは「試合中のメンタル管理」にある。

## メンタルの5要素（ノルウェーの教材から）

| 要素 | 言いかえ | 内容 |
|---|---|---|
| **できた実感** | 習得・達成感 | 「できた」という実感がやる気のもとになる |
| **自信** | 自信 | DFに仕掛ける・GKが飛び込むときの判断の土台 |
| **イメージ** | イメージトレーニング | プレー前に場面を頭の中で描く（成功を描く／起こりうる失敗と対応を並べる、の2通り） |
| **自分への声かけ** | セルフトーク | 「できる」「次はこうする」と自分に言う |
| **自分の合図** | 集中に入るきっかけ | 集中を高める自分だけの合図・決まった動作 |

## 試合前のメンタル準備

### イメージ

```
試合の前夜・当日朝・ウォーミングアップ中に行う

① 自分が成功するシーンを具体的に描く
   例：「右バックから廻旋フェイント → 内突破 → ループシュートが決まる」
② 視覚だけでなく、聴覚（声援・ボールの音）・触覚（ボールの感触）も含める
```

**描く中身は2通りある**〔まとめ〕

| 描き方 | やること | 起きやすいこと |
|---|---|---|
| うまくいく場面を描く | 決まる場面を動き・感覚まで細かく思い浮かべる | 動きの手順が整理される。思いどおりにいかなかったときの次の手は入らない |
| 起こりうる失敗を先に並べる | 止められる・読まれる場面を並べ、そのとき何をするかまで決めておく | 止められた後の次の手が先に入る。並べるだけで対応を決めないと不安だけが残る |

どちらが合うかは人による。両方やる人もいる。
「失敗を思い描くと失敗が体に刷り込まれる」と言われることがあるが、根拠は確かめられていない〔未確認〕。

**補足**：イメージトレーニングを習慣にしている一流選手は多いと言われる（具体的な割合の出どころは確かめられていない）〔未確認〕。
「頑張る」「勝つ」のようなぼんやりしたイメージより、**動作や感覚まで細かく描く**方が使いやすいと言われる。

---

### 自分の合図（メンタルトリガー）の作り方

```
試合前・プレー前に「集中スイッチを入れる」自分だけの合図

例：
- ボールを持つ前に右手でボールを2回叩く
- フリースロー前に深呼吸を3回
- タイムアウト後に味方とハイタッチ
- ベンチに座るときに右足から座る

ポイント：同じ動作を毎回繰り返す
→ 同じ動作を毎回くり返すと、その動作が集中に入る合図になりやすいと言われる
```

**注意**：迷信的になりすぎない（「やらないと負ける」と思うとプレッシャーが増える）。

## 試合中のメンタル管理

### ミス直後の立て直し（3秒ルール）

ミスの直後の扱い方は2通りある〔まとめ〕。

| 扱い方 | やること | 起きること |
|---|---|---|
| すぐ切り替える（下の3秒ルール） | 次にやることを一言決めて前のプレーを離す | 引きずりにくい。なぜ止められたかは残らない |
| 短く振り返って組み替える | 「相手は何をしてきたか」を一つ確かめ、次の手を入れ替える | 同じ相手に同じ手で臨まなくなる。長くなると次のプレーに遅れる |

場面にもよる（守りに戻る最中は切り替え、次の攻撃までの間は振り返り、など）。以下は「すぐ切り替える」方法の手順。

```
ミスした瞬間：
0〜1秒：自分のミスを認識する（隠さない・否定しない）
1〜2秒：自分への声かけで「次は○○する」と言う
       NG：「あー」「最悪」（過去を引きずる）
       OK：「次はポストを見る」（未来に向ける）
2〜3秒：自分の合図発動（深呼吸・小さなジェスチャー）→ 集中再起動
3秒以降：次のプレーへ完全に切り替え
```

**長く引きずるミス vs すぐに切り替えるミス**：
- 引きずる選手：1つのミスの後、続けてミスが出やすい（何プレー続くかの数字は確かめられていない）〔未確認〕
- 切り替える選手：次のプレーで小さな成功 → できた実感→ 自信回復

### プレッシャー下の集中

**プレッシャーが高い状況の典型**：
- 残り2分・1点差
- 7m投擲（反則で与えられる、GKと1対1で打つペナルティスロー）
- タイムアウト後の1本目
- 5連続失点で味方が崩れている
- 大事な試合の開始時（自分への期待）

**プレッシャー下の認知低下**：
- 視野が狭くなる（中央集中視野＝正面の一点ばかり見て、左右の味方やスペースが見えなくなる状態）
- 判断時間が長くなる（情報処理が遅れる）
- 体が硬くなる（フェイントが効かない）

**向き合い方の種類**：この章の「緊張との向き合い方」にまとめてある（落ち着かせる／上げる／間を取る）。

**どの型でも使える見方**：
```
・視野を意識的に広げる（周辺視野を取り戻す）
・選択肢を絞る：絞ると判断は速くなる。そのぶん相手には読まれやすくなる。
  いくつ持ったまま動けるかは、その場面の準備（事前に相手のパターンを入れているか）で変わる
・自分への声かけを使う：「やれることをやる」「次の1プレーだけ」
```

### 接戦終盤の心理

**「終盤崩れ型」選手の特徴**：
- 残り時間ばかり気にする
- スコアボードを何度も見る
- 過去のプレーを後悔する
- 「今打たないと」という焦り

**「終盤強い」選手の特徴**：
- 「次の1プレー」だけに集中
- 残り時間に気を取られすぎない（時間の確認は役割の人やベンチに任せる、など）
- ミスの後の扱い方が決まっている（すぐ切り替える／短く振り返って組み替える）
- 「自分のシュート」を信じる（自信）

## メンタル状態の自己診断

### 試合中の自分の状態をチェック

```
Q1: 今、視野は広いか？
  Yes → 集中できている
  No  → プレッシャーで狭くなっている → 自分の型に合った方法（落ち着かせる／上げる／間を取る）・視野広げる

Q2: 判断は速くなっているか？
  Yes → リズムに乗れている
  No  → 考えすぎかもしれない → 事前に決めておいた入口の手から入る、など（1つに絞りすぎると読まれやすい）

Q3: ミスを引きずっているか？
  Yes → 自分に合う扱い方を使う（すぐ切り替える／短く振り返って組み替える）
  No  → 集中継続

Q4: 体は硬いか？
  Yes → プレーが止まっている間やベンチで、軽く体を動かしてほぐす
  No  → 良好

Q5: 自信はあるか？
  Yes → 仕掛ける勇気あり
  No  → できた実感（小さな成功）を作る：簡単なパスから始める
```

## 自分のレベル診断（技術・戦術・メンタル3軸）

### 技術レベル診断

```
【シュート】
□ レベル1: ジャンプシュートが安定して打てる
□ レベル2: 早打ち・最高点・下降中の打点を使い分けられる
□ レベル3: バックハンドフェイク・回転シュートが試合で使える
□ レベル4: GKタイプを見抜いて最適な打点・コースを選べる

【フェイント】
□ レベル1: 1〜2種類のフェイントを試合で使える
□ レベル2: 3〜5種類のフェイントを場面で使い分けられる
□ レベル3: ダブルフェイント原則（2種連続）・廻旋フェイントを実戦で使える
□ レベル4: DFの「何を見ているか」を読んで対応フェイントを選べる

【パス・ドリブル】
□ レベル1: 両手キャッチが安定。ワンハンドキャッチも可
□ レベル2: バウンスパス・ロブパス・ノールックパスが使える
□ レベル3: ドリブル中のフェイント（ジャブ・ヘジテーション等）が使える
□ レベル4: 受ける前の勝ち位置取りが意識せずできる
```

### 戦術レベル診断

```
【DF読み】
□ レベル1: クローズ/ワイドの違いがわかる
□ レベル2: 6-0/5-1/マンツーマンを見分けられる
□ レベル3: シフト/前への飛び出し/マークの受け渡しの動きを読める
□ レベル4: DFタイプから最適なOFアクションを選べる

【GK読み】
□ レベル1: GKが動くか動かないかを観察できる
□ レベル2: 先読み型/コース絞り型を見分けられる
□ レベル3: GKタイプから打点・コースを選べる
□ レベル4: 試合中にGKタイプの変化を読み取って対応できる

【連携】
□ レベル1: ポストへのパスが出せる
□ レベル2: ギブ&ゴー・ピック&ロールが使える
□ レベル3: クロス・3人ウェーブ等のコンビネーションが使える
□ レベル4: チームのOFタイプを理解して自分の役割を果たせる
```

### メンタルレベル診断

```
【プレッシャー耐性】
□ レベル1: 普通の場面で集中できる
□ レベル2: ミスの後、自分に合う方法で立て直せる
□ レベル3: 接戦終盤でも視野が狭くならない
□ レベル4: プレッシャーをむしろ集中の源にできる

【整え方】※難しさの順番はない。レベルではなく、方法ごとに印をつける
　印①：試した／まだ　　印②：合った／合わなかった／まだ分からない
・自分の合図
・イメージ
・自分への声かけ
・小さな成功から自信を戻す（できた実感 → 自信）
```

## メンタルじゃんけん

```
プレッシャー高い
  → 視野狭くなる・判断遅れる
  → 自分の型に合った方法で向き合う（落ち着かせる／上げる／間を取る）
  → 成功 → できた実感 → 自信回復
  → 余裕が出る → プレッシャー耐性アップ

ミスする
  → すぐ切り替える（「次は○○」と決める）／短く振り返って手を入れ替える、のどちらか
  → 次のプレーで小さな成功
  → できた実感回復
  → ミス連鎖を断ち切れる

接戦終盤
  → 残り時間気になる
  → 「次の1プレーだけ」に意識を絞る
  → ミスしても引きずらない
  → 終盤強い選手になる
```
