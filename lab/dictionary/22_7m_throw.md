## 【A】7mスローの決まり（要点）

> どんな反則で7mスローになるかは `30_rules_and_referee.md`【H-2】にまとめてある。ここは投げる人・守る人が覚えておく要点だけ。〔日本ハンドボール協会 競技規則 2026年版 第14条・第15条・第8条8で確認〕

- 7mスローは、反則でつぶされた「明らかな得点チャンス」を取り戻すためのスロー。
- 笛が鳴ってから **3秒以内** に投げる。
- 立つ場所は、7mラインから後ろ1mまで。ボールを離す前にラインに触れない・踏み越えない。
- **片方の足の一部を床に着けたまま** 投げる（もう片方の足は上げ下げしてよい）。跳んで投げることはできない。
- 投げたあと、ボールが相手かゴールに触れるまで、投げた人も味方もボールに触れない。
- GKは、ボールが手を離れる前に **4mの線（ゴールキーパーライン）** を越えない。越えて得点にならなかったときは投げ直しになる。
- ほかの選手は、ボールが手を離れるまでフリースローライン（9mの破線）の外にいる。守る側は7mラインから3m以上離れる。
- 投げる人が位置についたあとは、GKを交代できない。
- GKが頭をボールのほうへ動かしていないのに、頭にボールを直接当てると、投げた人は2分間退場になる。

## 【B】エリートレベルの統計データ

```
【成功率】（フロンティアズ（学術誌） in 心理学 2026年研究：2007〜2024年・43大会・12,033本分析）
  全体成功率：73〜78%（男女とも）
  男性エリートリーグ：75.6〜77.7%
  女性エリートリーグ：73.4〜78.1%
  → 約4本に1本がGKセーブ or 枠外

【GKセーブの内訳】
  不成功の74.6%がGKセーブ（男性78.9%、女性70.9%）
  → 残り25.4%は枠外・ポスト・クロスバー

【2024年大規模研究の重要知見】（Tandfonline・男性95名・女性104名）
  ポジション・身長・体重・利き腕は7m成功率に有意差（＝偶然では説明できないはっきりした差）をもたらさない
  → 7mの勝負は身体的特性ではなく技術・心理・戦略で決まる
```

## 【C】シューターの技術

### C-1. 主要な4シュートタイプ

**① スタンディングスロー（立ち打ち）**
```
両足を地面につけたまま投じる基本形
安定性が高く、コントロール重視
7メートルスローで最も一般的な選択肢
フェイントとの組み合わせが有効
```

**② ロブショット（ループシュート）**
```
ボールに比較的急な放物線軌道をつける
GKが前傾姿勢・前方に出てきた場合に効果的
心理戦：GKを前に引き出してからロブを使う高度な判断が必要
```

**③ バウンスショット（バウンドシュート）**
```
フロアにバウンドさせてからゴールに入れる
GKの手や足の下を通す目的
研究：7mスローの4分の1以上でバウンスシュート or ボディフェイントが使われる
ドイツ・スペインコーチ教材で重要技法として位置付けられる
```

**④ スピンショット（回転シュート）**
```
ボールに横回転をかけてバウンド後に方向を変える高度技法
ウィングシュートで多用される技法のペナルティ応用版
```

### C-2. 生体力学的原理

```
運動連鎖：
  近位部（体の中心に近い部分＝腰・肩）から遠位部（末端＝肘・手首）へ順番に動かすことが最大球速を生む

ボール速度：
  7メートルスローの最大球速：約20 m/s（時速72 km）
  ゴールまでの飛行時間：0.35秒以下

速さと正確さの兼ね合い（両立しにくく、一方を上げると他方が下がりやすい）：
  7mではGKの存在が球速と精度のバランスに影響する
  上級者にはこの兼ね合いがあまり見られない
  → 初心者はGKがいると速度を上げるが精度が落ちる
  → ジュニア以上では有意差なし（訓練で克服可能）

ジャンプスロー禁止の意味：
  通常の試合ではシュートの7割強がジャンプスローと言われる〔未確認〕
  → 7メートルではこれが禁止されるため、スタンディング技術とフェイント技術が特に重要
```

## 【D】シューターの戦略

### D-1. 2つの基本戦略

**戦略①：GK非依存型**
```
事前に狙いを決め、GKの動きを無視して強さと精度を最大化
高速シュートで角を正確に狙う
上段コーナー（クロスバー＝ゴール上の横棒の直下）への強烈なシュートは最も防ぎにくいゾーン
→ GKタイプが読めない時・精神的余裕がない時に有効
```

**戦略②：GK依存型**
```
GKの動き出しを読み、その逆を突く
GKが早めに動いた場合 → ロブや逆サイドを狙う
GKが静止している場合 → フェイントで誘ってから投じる
→ 高い観察力と判断力が必要。GKを事前に観察しておくことが前提
```

### D-2. コーナー・高さ選択

```
スペインの研究（2017年）の知見：

得点になりやすい条件：
  ・左利き選手による高いアーム位置からのスロー
  ・強くて速い直線軌道またはバウンドシュート
  ・フェイントなし（直接投じる）
  ・GKがシューターから距離を取っている場合
  ・GKが「閉じた姿勢」のとき

左利き優位の研究（PMC 2024）：
  左利きシューターはGKにとって有意に予測しにくい
  GKは左利きへの予測精度が低い
  → 視線の当て方ではなく、左利きの動きパターンの視覚解釈が困難なことが原因
```

### D-3. GKタイプ別の対応

```
早期動作型（先読み型）：
  ボール離手前から動く → フェイントに弱い
  → 対応：スタンディングスローで引き付けてから逆サイドへ
         ロブで動いた方向の上を越す
         フェイント後に動き出しを確認してから投げる

反応型：
  ボール離手後に方向確認 → 物理的に間に合わない可能性大
  → 対応：フェイントはあまり効かない
         強速シュートで角を狙う
         コース絞りで力押し
```

## 【E】GKの7メートル防御技術

### E-1. 根本的ジレンマ

```
ボール飛行時間：0.35秒以下
人間の反応時間：約0.2〜0.3秒

→ 純粋な「見てから動く」反応では物理的に防御不可能

エリートGKの結論：
  予測的な動作開始が必須
  しかしフェイントに騙されるリスクが生じる
  → このジレンマが7メートルをハンドボール最大の心理戦場面にする
```

### E-2. 基本の立ち方

```
膝を軽く曲げ、重心は前足部（拇指球）に
両腕を体側から少し離し、手のひらをシューターに向ける
ゴールラインから1〜1.5メートル前に立ち、4メートルラインまでの空間を活用
→ シューターの角度を狭める

オフセット基本姿勢：
  体をシューターの利き腕側の角度を優先してカバーする斜め構え
  → 特定コーナーへのシュートを誘発しながら、反対側をカバーする戦術的配置
```

### E-3. タイミング戦略

| タイプ | 内容 | リスク |
|---|---|---|
| 早期動作型 | 身体キューを読んでボール離手前に動く | フェイントに弱い |
| 反応型 | ボール離手後に方向確認してから動く | 物理的に間に合わない |
| 混合型 | キューを読みながら動作開始を微調整 | 高い経験と練習が必要 |

### E-4. 視線戦略（科学的根拠）

```
研究（PMC 2025・エリートGK40名対象）：

男性GKの視線：上腕・前腕・ボールを主に観察
女性GKの視線：胴体・頭部を主に観察
→ 異なる戦略で同程度の防御成功率を達成

クワイエット・アイ（視線を一点に止めること）：
  有効な防御動作では、無効な動作に比べてクワイエット・アイ時間が有意に長い
  男性：平均差122.83 / 女性：平均差92.26
  → 一点を静止して見る時間が長いほど防御成功率が高い

エキスパートGKは非専門家より正確に方向予測できる（特に右利きシューターに対して）
左利きへの対応：GKの予測精度が有意に低い（視覚パターン認識の問題）
```

### E-5. 読み取る手がかり

```
優先順位順：
① 肩と腕の方向（上腕・前腕の向き） ← 最重要
② 体幹の傾き・回転方向
③ 手首の角度とグリップ
④ アプローチの速度とリズム
⑤ 足の向き・踏み出しの角度
⑥ 目線（ただし経験者は意図的に外す）
```

### E-6. GKの心理的プレッシャー戦術

```
合法的な戦術：
  ・ゴールラインからの前進（4メートルラインまで）→ 角度を狭める
  ・「見せかけの傾き」でシューターの決断を誘発
  ・ポジション変更・大袈裟な動作でシューターの注意を分散

注意：
  GKはシューターの投げる動作を開始した後に不正な動作で妨害してはならない

スポーツ心理学的優位性：
  GKはペナルティで「負け役」として位置付けられる
  → 入れられても「想定通り」。精神的プレッシャーはシューターより軽い
  → この非対称性を認識し、積極的かつ大胆に動くことが奨励される
```

## 【F】心の面

### F-1. シューター側の心理管理

```
7メートルスローは技術的条件が固定されながら心理的プレッシャーが最大化される稀有な場面

コントロールすべき4要素：
  注意集中 / 覚醒レベル / 感情反応 / 運動実行

統計的傾向：
  男性選手：試合終了前ラスト5分間で成功率が下がる傾向（平均 -1.4pp＝パーセントポイント）
  女性選手：ファイナル5分間で成功率が上がる傾向（+2.7pp）
```

**プレショット・ルーティン**
```
一貫したルーティンを持つ選手はプレッシャー下でより安定したパフォーマンスを発揮
例：ボールを3回ドリブル → 深呼吸 → 視線をコーナーへ → 投げる
→ 毎回同じ動作をくり返すと、それが集中の合図になりやすいと言われる
```

**セルフトーク**
```
インストラクショナル型：「右上角、強く」など技術的な言葉
モチベーショナル型：「できる」「落ち着け」など自信強化
→ どちらにも効果を示す研究がある
```

**チョーキング vs Yips（違いを知る）**
```
チョーキング：
  高プレッシャー時の不安による運動パフォーマンス低下
  正しい動作は認識できるが身体が思い通りに動かない
  → 訓練とルーティンで対処可能

Yips（イップス）：
  ストレスで誘発される制御不能な不随意運動
  チョーキングより深刻な状態
  → 専門的なメンタルサポートが必要
```

### F-2. イメージ

```
成功シュートの視覚化が集中力・自信に貢献（IHF/EHFコーチング教材より）
実践方法：
  投げる前に「成功するシーン」を0.5〜1秒間頭に描く
  視覚だけでなく、ボールの感触・音・歓声も含める
  うまくいく場面だけ描くか、止められる場面と対応も並べるかは、自分に合うほうで（`18_mental.md`）
```

## 【G】タクティカルファウル（反則で止めること）

### G-1. 反則で止めて7mになる場面の損得

- 「決められそうな場面は、反則で止めて7mにしたほうが得」という考え方が紹介されることがある。
- ただし、7mは高い割合で決まる（この章の【B】）。反則のしかたによっては2分間退場や失格が加わり、7mと人数の不利が重なる。速攻中の接触は、ケガの危険も大きい。危ない止め方はしない。
- ファウルの損得は `08_game_management.md`「ファウル戦略」のコーチ直伝にまとめてある（フリースローで止められる位置なら損が小さい／7mと退場は割に合わない／GKと1対1になったらGKに任せる）。
- 試合終了前30秒間は、反則で相手のスローやシュートの機会をつぶすと、失格（その試合に戻れない）に加えて相手に7mスローが与えられる（第8条11。くわしくは `30_rules_and_referee.md`【H-2】）。

## 【H】トレーニング方法

### H-1. シューターのプレッシャー練習

```
ゲーム状況のシミュレーション：
  試合開始直後・タイムアウト直後・大量ビハインド・残り30秒
  など具体的な状況設定で練習する

連続7mシュート：
  成功・失敗に関わらず次のシュートへの心理的リセットを習慣化
  → 「次の1本だけ」の意識（18_mental.mdの自分への声かけ参照）

プレッシャー環境の設定：
  チームメイトの観衆の前で打つ
  成功/失敗に対するゲームルールの導入（失敗したらダッシュなど。罰を付けるかどうかはチームによる）

射法の習得順序：
  1. スタンディングスロー（基本）
  2. バウンスショット
  3. ロブショット
  4. フェイント付きスタンディング
  5. GKタイプ別の対応
```

### H-2. GKの防御練習

```
視覚キュー訓練：
  ビデオ分析でシューターの身体部位への注意集中を訓練
  実地：上腕→前腕→ボールの順に視線を移す練習

クワイエット・アイの練習：
  一点を静止して見る時間を意識的に長くする練習
  → ホッケーGKで有効性が証明。ハンドボールでも研究中

動作開始タイミング訓練：
  早すぎず（フェイントに弱い）遅すぎない（間に合わない）バランスを訓練
  フェイント付き・なしを混在させた練習が有効

左利きシューターへの対応：
  左利き選手との反復練習で視覚パターン認識を向上させる
```

## じゃんけん構造（7メートル）

```
シューター：GK非依存型（強速コーナー）
  → GK：事前に角度を絞って角を狭める
  → シューター：ロブや逆コーナーを選ぶ

シューター：フェイント型（GK依存型）
  → GK：早期動作をやめて待つ（Reaktion型）
  → シューター：強速シュートで押し切る

GK：積極的前進（角度絞り）
  → シューター：ロブショットが有効
  → GK：前進を控えて待つ
  → シューター：角への強速シュートが有効

→ 7メートルに「絶対に入る」方法も「絶対に防ぐ」方法も存在しない
→ 相手の特性・試合状況・心理状態によって最適解が変わる
```
