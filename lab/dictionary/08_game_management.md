# ゲームマネジメント・ファウル戦略

> **この章を開く場面**：リードしているとき・追いかけているときの試合の進め方、残り時間の使い方、ファウルの損得、タイムアウト、GKを外した7人攻撃で迷ったとき。

---

## パッシブプレー

### ルールの要点
- 審判が予告の合図（片腕を上げる）を出したら、そのあとのパスは **4回まで**。それまでにシュートを打つ。
- 数え方の細かい決まりと、合図が取り消される場面は `30_rules_and_referee.md`【D】にまとめてある。大会によって回数が違うことがあるので、要項も見る。

### 合法的な時間の使い方
- ボール回しは合法（DFを動かしながら回す）
- ドリブル突破の試みを見せながら回す
- ポストへの当てパスを繰り返す（毎回シュートの脅威を見せる）
- シュートフェイクを入れてGKを動かす

### パッシブプレー回避チェックリスト
1. 常にシュートの脅威を見せているか
2. DFを動かしているか（静止したボール回しはNG）
3. ポストへの当てパスを使っているか
4. 予告の合図が出たあと、残りのパスで何を狙うかが決まっているか

## ゲームクローズ（リードを守る）

### タイミングマトリクス

| リード差 | 残り時間 | 戦術 |
|---|---|---|
| 5点以上 | 10分以上 | 通常のポゼッション |
| 5点以上 | 5分以内 | 徹底したボールキープ・タイム使い |
| 3-4点 | 5分以内 | バランス維持・確実なシュート選択 |
| 1-2点 | 2分以内 | セーフシュート（外す危険が低い確実なシュート）を選ぶ・無理な速攻は控える |
| 同点 | 終盤 | 先取点で心理的優位 |

### ボールキープ技術
- ポストにボールを入れて保持する（相手は反則で止めることが多く、時間が進む）
- コーナー付近でのキープ
- ファウルされたらすぐに立つ（プレーを続けるふり）

## ファウル戦略

### ファウル（罰則）の種類と重大度（2025年競技規則 第16条 + コーチ直伝）

ファウルは一括りにしてはいけない。「何が与えられるか」で意味が全く違う。

---

#### 【ボールの扱いによる結果】

**① フリースロー（第13条） ◎ ナイス**
- 相手に9m付近以遠からの攻撃権を与える
- GKとDFが整う時間が生まれる → 守りやすい状況
- 戦術的に与えてよいファウルの結果
- 与える位置が重要：ゴールから遠い位置ほど良い
- 主な発生原因：軽微な接触・パッシブプレー・段階的違反

**② ペナルティスロー（7mスロー）（第14条） ✗ ダメ**
- ゴール正面7mからのフリーシュート。GKと1対1
- トップレベルの成功率は73〜78%（→ `22_7m_throw.md`）。4本に3本は決まる
- 主な発生原因：
  - ゴールエリア内（6mライン内）でのDFの反則
  - 明確な得点機会（シュート動作中・フリーでゴールへ向かっている）を妨害
  - 試合終了前30秒間の、規則で決められた重大な反則（第8条11）
  - コート外の人物がボールに触れる等
- DFとして最も避けるべき状況

---

#### 【選手へのペナルティ】

**③ 警告（イエローカード）（第16条1） △ 受け取ったら修正をかける**
- 各チームに最大3回まで。選手個人には1回のみ
- 意味：「**この審判はこの基準で吹く**」というアナウンス
- 受け取ったら：次のプレーから基準に合わせて修正をかける
- 戦略的読み方：どのプレーで警告が出たかを記録して審判の基準を把握する
- 警告自体はプレー継続できるが、同じ行為の繰り返しは②退場に直結する

**④ 退場（2分間除外）（第16条3〜5） ✗✗ いかなる場合もダメ**
- 2分間フィールドから除外。チームは5on6の数的不利
- 退場中は交替選手を入れられない（2分後に戻れる）
- 同一選手が3回退場 → 失格
- コーチ原則：**「退場と天秤にかけて上回るものは基本的にない」**
- 1点を止めるためでも退場は割に合わない（2分間の5on6は複数失点リスク）
- 主な発生原因：
  - 繰り返される反則
  - 明確な得点機会の妨害（7mにならない状況で）
  - 抗議行為・非スポーツマン的行為

**⑤ 失格（第16条6〜8） ✗✗✗ 絶対にダメ**
- その試合の残りは出られない。退場と違い、本人は2分たっても戻れない
- ただし2分経過後はチームに交替選手が戻ることは可（第16条8）
- 失格＋報告書（最も重い）：暴力行為など。試合後に報告書が出され、別に処分が検討される
- 主な発生原因：
  - 特に危険な反則・暴力行為
  - 非スポーツマン的行為の繰り返し
  - 競技役員・コーチへの侮辱行為

---

### ファウル判断の優先順位

```
①フリースローを与えることになる → ◎ 積極的に選べる手段
②7mスロー（ペナルティ）になる → ✗ 絶対に避ける
③警告が出る                    → △ 修正のシグナルとして受け取る
④退場（2分間）になる          → ✗✗ いかなる場合も避ける
⑤失格になる                   → ✗✗✗ 絶対にダメ
```

### 具体的な判断場面

| 場面 | 最善の判断 |
|---|---|
| 速攻を止めたい（ゴールから遠い） | ①フリースローになる位置でファウル |
| GKと1対1の状況（相手がフリー） | ファウルしない。どうせ②7mか④退場。GKに任せる |
| 6mライン付近での接触 | ②7mを絶対に与えない。ファウルするなら外側で |
| 外シュートのみの場面 | GKに任せてファウルしない |
| 審判が③警告を出した | 「この審判のライン」を把握。同じプレーを繰り返さない |
| ④退場になりそう | 1点を失っても退場より良い。必ずファウルしない判断 |

### 第8条（反則行為）の要点

接触の線引き（どこまでが許され、どこから罰則になるか）は `30_rules_and_referee.md`【C-2】にまとめてある。要点だけ：

- 相手の体に向かった反則は、程度によって 警告 → 2分間退場 → 失格 と重くなる（8:3）。
- 危険な反則（頭・首への接触、後ろからつかむ・引き倒す、跳んでいる相手への接触など）は、警告なしで2分間退場になる（8:4）。
- 相手の体に害を与える反則は失格になる（8:5・8:6）。
- 明らかな得点チャンスを反則でつぶすと7mスローになる（14:1）。

## タイムアウト判断

### 取られることが多い場面（取ると流れが一度切れる。相手にも修正の時間ができる）
- 相手に3連続得点されたとき（モメンタムを切る）
- 相手のモメンタムが明確に出ているとき
- 重要なセットプレーの前（作戦確認）
- 選手が混乱しているとき

### 取ると損になりやすい場面
- 自チームのモメンタムが来ているとき（流れを切ってしまう）
- 試合序盤（後半に温存する）
- 相手DFが崩れているとき

### タイムアウト明け
- 最初のプレーを決めておくと、全員が同じ絵で動ける（請求の決まりは → `30_rules_and_referee.md`）

## 7on6（GK外し）

### 発動タイミング
| ビハインド | 残り時間 | 推奨度 |
|---|---|---|
| 2点差 | 残り2分 | ◎ よく使われる |
| 3点差 | 残り4分 | ○ 状況次第 |
| 4点差 | 残り7分 | △ 早めの博打 |
| 1点差 | 残り30秒 | ○ 最終手段 |

### GKを外すタイミングとサイン
- **フリースロー時**：最も安全。DFが整っている間にGKが走れる
- **ゴールスロー後**：GK自身がコートに残って外から入れ替わる
- **タイムアウト明け**：7人が最初から揃った状態でスタートできる
- **サイン**：コーチが特定の言葉（コールワード＝あらかじめ決めた合図の言葉）を叫ぶ / GKへ手で合図するジェスチャー

---

### 7on6 フォーメーション

**パターンA：3-3フォーメーション（標準）**
```
　　　　LW　　　　　　RW
　バックライト　　バックレフト
　　　バックセンター
　　　　　PV
（LW＝左ウィング、RW＝右ウィング、PV＝ポスト〔6m上に構える〕。バックライト/バックレフト/バックセンターは後方の右/左/中央のバックプレーヤー）
```
- 外野3人・内側3人（PVは6mライン上）
- ボール回しで相手DF7人を動かしてから崩す
- ポストが空いていれば、素早いパスが効きやすい

**パターンB：2-4フォーメーション（ポスト2枚）**
```
　LW　　　　　　　　　RW
　　バックライト　バックレフト
　　　PV左　　　PV右
```
- ポスト2人を6m左右に配置
- どちらかにパスが通れば至近距離からのシュート
- DFが2人を同時にケアしにくい

**パターンC：4-2フォーメーション（外野4人）**
```
LW　バックライト　バックレフト　RW
　　　　PV　バックセンター
```
- 外野4人でパスを回してDFを横に引き伸ばす
- 引き伸ばした後にポストへ通す
- 遠距離シュート力が高いチームに有効

---

### 7on6 攻撃の入口の例

```
7on6開始直後：
│
├─ ポストへの即パスコースはあるか？
│   YES → 即パス → ポストがシュート
│   NO  ↓
│
├─ 外野4人でのボール回しでDFを横に動かす
│   → 1人が「クローズ」（DFが内側に寄って間合いを詰めてきた状態）を確認したら逆へ展開
│   → 逆端でシュートチャンスがあれば打つ
│   → なければ再びポストへ当てパスを試みる
│
└─ フリースロー or タイムアウト取得 → リセット
```

**7on6でやってはいけないこと（失敗パターン）**：

| 失敗 | 結果 |
|---|---|
| パスミスでボールロスト | 空ゴール失点ほぼ確定 |
| 急ぎすぎて判断が雑になる | DFがインターセプト → カウンター |
| 外シュートを急いで打つ | GKなしでも外れたら終わり |
| ポストへのパスにこだわりすぎる | 時間切れ / パッシブの予告合図 |
| 全員がゴール方向を向く | ボールロスト時に誰も帰れない |

**リスク管理の原則**：
```
7on6 = 「1点以上を取りに行く」ではなく「1点差を縮める可能性を作る」
→ 無理なシュートより確率の高いシュートを選ぶ
→ ボールロストしたら空ゴール → 逆に点差が広がる最悪のシナリオ
```

---

### 相手の7on6対策（DFとして）
- 空ゴールへのロングシュートを常に狙う（インターセプト = 空ゴール直行）
- ボールロストを誘うプレッシャー（ただし7mを与えないこと）
- コンパクトゾーンで5on6を守り切る（全員でゴール前を固める）

## モメンタム管理

### モメンタムが来ているサイン
- 連続得点（3点以上）
- GKのビッグセーブ連続
- 相手のミスが増えている
- スタンドの雰囲気

### モメンタムを維持する
- 選手交代を最小限にして流れを切らない
- タイムアウトを取らない（相手に修正の機会を与えない）
- 高いプレッシャーを継続する

### モメンタムを取り戻す
- タイムアウト（流れを一度切る）
- 選手交代（空気を変える）
- DF陣形変更（パターンを崩す）
- GKへの声かけ（精神的サポート）

## 時間帯別戦術（前半・後半・終盤）

### 前半序盤（0〜10分）
- 相手のDF強度・システムを確認する偵察フェーズ
- エースを温存しつつ攻めてDFの弱点を探る
- GKのタイプ（先読み型/コース絞り型）を3〜5本で特定
- 確実な選択肢を優先（スロースタートを避ける）

### 前半中盤（10〜20分）
- 最初の10分で得た情報をもとに攻め方を確立
- ポストの活用を増やす（DFが疲れ始める）
- 相手のタイムアウト残数・退場リスクを把握

### 前半終盤（25〜30分）
- ハーフタイム前の1点は心理的影響が大きいと言われる〔未確認〕
- 相手のタイムアウト残数を確認して使わせる

### 後半序盤（30〜40分）
- ハーフタイム修正の実行テスト（相手も修正している）
- 相手の修正を読んでカウンター修正

### 後半中盤（40〜50分）
- 疲労差の活用：足が止まってきたDF選手への集中攻撃
- 選手交代で自チームの疲労をリセット

### 後半終盤（残り5分）
- 1点の価値が最大化
- タイムアウトの使い時判断が最重要
- 7on6発動タイミングの判断

### ラスト2分
- 負けているチーム：7on6最終手段
- パッシブの予告合図回避：ボールを早く回す
- 勝っているチーム：速攻しない・時間を使う

### ラスト30秒
- 負けているチーム：無理でもシュートを打ち、リバウンドを狙う
- 勝っているチーム：ファウルさせながらボールキープ

## 退場者が出た場合

| 状況 | 戦術 |
|---|---|
| 自チームが2分間退場（5on6） | DFラインを引いてコンパクトゾーン・攻めは急がず時間を使う |
| 相手が2分間退場（6on5） | 積極攻撃・素早い仕掛け（退場選手が戻る前に） |
| 自チーム主力が退場 | 代替選手投入・残選手でシステム再構築 |
| 複数名退場 | 守りを固める。7on6は失った時の失点の危険がさらに大きい |

### スコア差×退場の複合判断
```
リードしている状態で自チーム退場
  → コンパクトゾーンで2分を0点で凌ぐ
  → 速攻は、失うと人数の少ない状態で逆に速攻を受ける

負けている状態で相手チーム退場
  → 最大限の攻撃（6on5を使い切る）
  → 退場選手が戻るまでの2分間が人数の多い時間
```
