## 【グローバルトレンド 2025】

### 7on6（GK外し）戦術の実態データ（2020-2023研究）
- **使用タイミング**：主に試合終盤、小差でビハインドのときに発動
- **空ゴール失点率**：17.7%（= ロングシュートで簡単には入らない）
- **内訳**：シュートなし攻撃での失点40.9% / 不成功シュート後の失点19.7% / 得点シュートの失点5.9%
- **実用示唆**：「ボールを持ち続けさえすれば空ゴール失点リスクは低い」。問題はボールロスト
- 2016年ルール改正後：2ポスト配置、5+1等の多様な7on6フォーメーションが登場

### じゃんけん（グローバル）
```
ゾーン守備（コンパクト6-0） → 外シュートを打たれ続ける → 5-1に変更
→ 前衛の裏をポストで使われる → ゾーンに戻る

守備優位（低失点チーム） → 速攻で少ない得点を守る → ポゼッション攻撃に弱い
→ 相手が時間を使うポゼッション → カウンターチャンスが減る → 守備型チームが不利に

7on6（GK外し） → コンパクトゾーンで守られる → ポスト2枚配置でゾーン崩す
→ 空ゴールへのロングシュートカウンター → 7on6を早めに解除 → 得点機会が減る
```

## 【デンマーク】 コレクティブDF + クイックスローオフ

### 戦術的特徴
| 局面 | 特徴 |
|---|---|
| OF | **クイックスローオフ**（得点直後の素早い再開）が軸。エース依存ではない集団得点 |
| DF | コレクティブDF（集団的組織守備）。失点の少なさで知られる |
| サインプレー | コード化されたサインプレーが体系化されている |
| 強み | 「特定の陣形」より「全員が役割を果たすシステム」 |

### じゃんけん（デンマーク対策）
- クイックスローオフ → 数人をDFに残して速攻カウンターを準備
- 整ったDFを崩す → 外シュート+ポストの2軸で同時に守れない状況を作る
- コード化システム → 同じ陣形で対応せず、毎回少しずつ違うパターンを見せて読みを外す

## 【フランス】 école française（多機能性 + アグレッシブDF）

### 戦術的特徴
| 局面 | 特徴 |
|---|---|
| OF | ダイナミックなポスト活用、バックプレーヤーが内外を使い分け、セットプレーのバリエーション豊富 |
| DF | アグレッシブな6-0ゾーン、前線プレッシャーとゾーン守備の組み合わせ |
| 多機能性 | 各選手が複数の役割を担う（左利き右バックの伝統育成あり） |

### 「école française」 = 多機能性の具体

```
1人の選手が複数ポジションをこなす：
- バックがポストに入る瞬間 → 突然の2ポスト
- ウィングが中央に切り込む瞬間 → 突然の3バック
- センターがウィングに動く瞬間 → DFのマーク混乱

→ DFが「誰が何をするか」を読み切れない
→ マンツーマンが効かない（追従が追いつかない）
```

**目合わせで動き出すポスト**（動きの例）：
- パワーで6mラインを守る ＋ アイコンタクト（ブリックコンタクト）でバックに「今だ」を伝える
- DFが見ていない側に走る「フラッシュタイミング」（DFの視線が外れた一瞬を突いてゴール前へ素早く走り込むこと）が極めて正確

### じゃんけん（フランス対策）
- アグレッシブ6-0 → 6-0の3原則（圧縮/飛び出し/受け渡し）の完成前を突く
- 多機能選手 → マンツーマンで追わず、ゾーンで領域を渡す（個別マークが追い切れない）
- 左利き右バック → 右ブロックDFで対応（シュートコースを左側から塞ぐ）
- 目合わせで動き出すポスト → アイコンタクト（ブリックコンタクト） 成立前にバック側にプレッシャーをかけて目を合わせさせない

## 【スペイン】 ポジショナル + ポスト中心

### 戦術的特徴
| 局面 | 特徴 |
|---|---|
| OF | 厳密なポジショニング、空間を作って使う、ポスト経由セットプレー |
| DF | 組織的ゾーン守備 |
| 哲学 | 「一手先を読む」ポジショナルプレー、固定役と浮き役（パル/インパル）理論によるポスト浮き |

### 固定役と浮き役（パル/インパル） 理論（核心戦術原則）

スペイン式戦術の中核。バックプレーヤーが**常に確認すべき2つの状況**：

```
Par（パル＝偶数）  = 自分の直接的なDFマーク相手
Impar（インパル＝奇数）= 直接DFの両側に立つDF選手（自分にとっては「ズレた」DF）

【連続突破（penetraciones sucesivas）の論理】
① OFが自分のParを「固定（fijar）」する（ドライブ・脅威）
② 隣のDF（Impar）が寄ってカバーしようとする
③ 反対側にImpar（浮き）が生まれる → そこが空く
④ そのフリー選手を使う
⑤ DFが対応 → さらに別のImparが生まれる … 連続的に発生
```

→ 「**1人を固定して、隣を浮かせる**」を連鎖させるのがスペイン式。

### 2:2（バック×ポスト）の永続的探求

スペイン代表・バルセロナ・ASOBALリーグで共通して見られる**最重要パターン**：

```
バックプレーヤー（前線）＋ ポスト の2人で「ダイヤモンド状況」を作る

① セントラル/バックがDFを「固定（fijar al defensor par）」
② ポストがImpar（浮きDF）の側のスペースへ走り込む（Freilaufen）
③ バックがポストへ対角パス → ポストがシュート or 倒れ込み

または：
① バックがシュートフェイント → DFを引きつける
② ポストDFがヘルプに来る → ポストが浮く
③ 逆サイドのバックがフリーになる（連鎖突破）
```

詳細は `14_position_roles_international.md` の「センター×ポスト連携（最重要）」参照。

### じゃんけん（スペイン対策）
- ポジショナル攻撃 → 想定外の位置取り（オフボール動き直し）でDFラインを崩す
- ポスト経由 → ポストへのパスコース封じが基本
- 固定役と浮き役（パル/インパル）連鎖 → **「最初の固定」段階で全力プレッシャーをかけて連鎖を止める**
- 2:2状況 → ポストDFに「ヘルプに行かない」訓練が必要（ヘルプ＝Imparが浮く）
- 「読み」が強い → シンプルな単発アクション（連続シュートフェイント等）で読みを混乱させる

## 【スロベニア】 革新的（5on5戦術）

### 戦術的特徴
| 局面 | 特徴 |
|---|---|
| OF | 高速トランジション、流動的なポジション |
| DF | コンパクト守備 |
| 革新性 | **6on5でもあえて5on5を維持**する判断 |

### あえて5on5を選ぶ戦術
- 通常6on5（ライン選手＝ポストを1人追加投入して数的優位を作る）の場面で**あえて5on5を維持**
- 狙い：数的有利の混乱より、速い切り替えと守備のコンパクト性を優先
- 結論：「**数的優位は条件付きでのみ有効**」（自チームの強みと合致するときのみ）

### じゃんけん（スロベニア対策）
- 高速トランジション → バックチェック必須
- 流動的ポジション → マンツーマン気味の対応が無効化される → ゾーンで対応
- 5on5志向 → 数的優位を作っても効果が薄い → 質的優位（個人技差）で勝負

## 【GKシステムの国際比較】

### 共通の現代トレンド
- ハンドボールの高速化 → GKが至近距離の1on1場面に頻繁に対処する必要
- 手や腕より**フットワークと立ち位置が優先**（足が合ってから手を出す）
- 各ポジション（左/右/中）ごとの「セットポジション」の反復練習
- シューターの最高点に先取りする癖が「早打ちの標的」になる

### GKコーチ養成
- IHFが2段階のGKコーチライセンス制度を整備：
  - Lv.1：ユース年代向けGKコーチ育成
  - Lv.2：シニア（パフォーマンス志向）GKコーチ育成

### 国別育成傾向
| 国 | GK育成の特記事項 |
|---|---|
| デンマーク・フランス・ドイツ・ルーマニア | 13-14歳からDF・GKシステムを体系的に指導（比較研究あり） |
| アイスランド | 全国的な高い競技参加率が底上げ。コーチ育成も輸出水準 |
| ノルウェー | 専門家チーム（フィジカル・タクティクス・メンタル）が年代別にGKも指導 |

## 【辞書への応用：じゃんけんマップ追記】

### 国際水準から逆算した原則
```
「失点の少ないチームが強い」と言われることが示すもの
  → 守備の質 × 組織力 = 得点より失点管理が勝敗を決める
  → 参考になるのは「守備から速攻へのスイッチ精度」

「64点/試合（2025世界選手権平均）」が示すもの
  → 試合は高速化。1秒のズレが致命的
  → 「認知→判断→行動」の速度が全ての前提

「7on6の空ゴール失点17.7%」が示すもの
  → ボールを保持し続けることがリスク管理の本質
  → ロストが最大の敵

「あえて5on5を選ぶ」が示すもの
  → 数的有利は必ずしも最善手ではない
  → トランジションの速度と組織の安定を優先する選択肢がある

「アイスランドコーチ現象」が示すもの
  → 戦術は選手より「コーチ」を通じて伝播する
  → 一人の優れたコーチが複数の国を強くする連鎖が生まれる
```

## 【デンマーク補足：コードワード戦術（タイムアウト指示の体系化）】

タイムアウトで短いコードワードを使い、全員に攻撃意図を一瞬で共有する仕組み。日本のチームでも応用可能。

### ポジション番号体系
- **1's** = ウィング（両翼）
- **2's** = バック（両サイドバック）
- **3's** = 中央のインナー

### 主要コードワードと動きの内容
| コード | 動きの内容 | 目的 |
|---|---|---|
| **バルサ** | センターバックが左へ動く → 右バックにパス → 左バックがセンターバックとクロスして中央を走り抜けてボールを受ける | バックが1on1状況を作る。複数の選択肢を内包 |
| **ビルン** | ウィングがボールを持ち、弧を描いて右バックと相手中央DFの間のスペースへ走り込む | ランニングレーン（走るルート）の指定 |
| **det brede punkt** | 選手がベンチ側サイドライン際からスタート、相手バックとウィングの間を攻撃 | DFの横を大きく使って間を割く |

### 応用：自チームでコードワード化する手順
1. 主要パターンに2文字以内の名前を付ける（例：「クロス」「ウィング走り」）
2. タイムアウトと試合中の声でその名前だけを叫ぶ
3. 全員がパターンを把握していることが前提 → 練習で繰り返し定着させる

### じゃんけん（コードワード戦術への対処）
- DF側：ビデオスカウティングでパターンを解析する
- OF側：パターンを2〜3にとどめず、各パターンに「分岐」を作って読まれにくくする

## 【6-0守備の3基本動作（ドイツ語一次情報）】

> 出典：handballtraining.de、Wikibooks ハンドボール Taktik、VIBSS

### ドイツ語技術用語（世界標準）

| 用語（独） | 読み | 意味 |
|---|---|---|
| **シフト（フェアシーベン）** | フェルシーベン | ボール側へのライン全体シフト |
| **前への飛び出し（ヘラウスリュッケン）** | ヘラウスリューケン | インナーDFが前に飛び出すプレッシャー |
| **マークの受け渡し（ユーバーゲーベン）** | ユーバーゲーベン | 飛び出した後の隣へのマーク受け渡し |
| **DFの裏のスペース（ティーフェンラウム）** | ティーフェンラウム | ゴール前の危険な深さスペース（これを最小化するのが6-0の目的） |
| **司令塔（シュピールマッハー）** | シュピールマッハー | ゲームメーカー＝センタープレーヤー（5-1が狙う対象） |

### 6-0の3動作サイクル

```
① シフト（フェアシーベン）
   ボールが右に渡る → ライン全体が右へシフト
   → ボールサイドに密集 / 逆サイドに空間が生まれる（リスク）

② 前への飛び出し（ヘラウスリュッケン）
   インナーDFがボールを持つバックに前進プレッシャー
   → シュートコース圧迫 / パスコースを切る
   → 飛び出した背後にDFの裏のスペース（ティーフェンラウム）が生まれる（最大のリスク）

③ マークの受け渡し（ユーバーゲーベン）
   飛び出したDFが戻れない場合 → 隣のDFにマークを渡してラインを維持
   → 受け渡し失敗 → 穴が生まれる（攻撃のチャンス）
```

### じゃんけん（6-0の3動作を崩す）

```
シフト（フェアシーベン） → 逆サイドへの素早い展開でスペースを使う
前への飛び出し（ヘラウスリュッケン） → 飛び出した背後にポストを走り込ませる
マークの受け渡し（ユーバーゲーベン） → 受け渡しの一瞬にクイックパス → 瞬間的マーク外れを突く
```

### 5-1の本質（ドイツ語原典から）
> 「5:1は前への飛び出し（ヘラウスリュッケン）をシステム化したもの。前衛1人が常に相手の司令塔（シュピールマッハー）（センター）を制限する。特に相手センターが強力な場合に有効」

### 1stウェーブ/2ndウェーブの体系化
速攻を「第1波（1〜2人）」と「第2波（3〜4人合流）」に明確に分離し、全選手が役割を把握する。

| 局面 | 1stウェーブ | 2ndウェーブ |

### トランジションの判断訓練
- 「プレッシャー下でも正確な選択ができる」よう、時間制限付きの判断練習を体系化
- 相手の選手交代のタイミング・パターンを読んで戦術を調整（後半の疲労交代を利用）

### じゃんけん（トランジション構造化への対処）
- 1stウェーブ → 守→攻の切り替え時、ハーフコート付近にバックチェック要員を残しておく
- 2ndウェーブ → 1stが防げた直後の「2波目」を警戒（攻撃が止まったと油断しない）

## 【スロベニア補足：5on5戦術と「数的優位の条件付き有効性」】

### 5on5維持の戦術的根拠
**問題提起**：なぜ6on5（数的優位）を使わないのか？
- 6on5（ファウルで得た1人多い状況）→ 整ったセット攻撃 → スロベニアの「速さ」の強みが消える
- **5on5を維持**（あえて数的優位を使わず素早く攻める）→ 相手DFが整う前に得点

> 自チームの強みが「速さ」なら、数的優位より「速さ」を優先する判断。
> 原則：「**数的優位は自チームの強みと合致するときのみ有効**」

### 7on6（GK外し）の実行品質
7on6は決断だけでなく、チームの準備（事前パターン）が必須。準備が不十分なまま発動するとボールロスト→空ゴール失点に直結する。

### じゃんけん（スロベニア戦術への対応）
- 高速トランジション → 得点後に素早く守備陣形に戻る（相手の「速さ」を消す）
- セット攻撃での対決に持ち込む → スロベニアは個人技×組織が融合
- ゴール前での強引な決断を迫る展開に持ち込む（決定力が課題のチームへの対策）

### 戦術的特徴（スペイン式の移植）
| 局面 | 特徴 |
|---|---|
| **DF** | 6-0が基本、状況に応じて5-1を併用。**スペイン式の「規律あるゾーン」**を導入 |
| **OF** | バックプレーヤーのジャンプ力を活かした外シュート + スペイン式ポスト中心攻撃 |

### スペイン式の移植の中身
スペインのリーグ出身の監督が導入したとされる戦術のまとまり：

1. **6-0の規律化**：3原則（圧縮/飛び出し/受け渡し）の徹底訓練でフィジカル任せからの脱却
2. **セットプレーのパターン化**：パッシブの予告合図後の30秒で実行する固定パターンを多数準備
3. **ポストの組織化**：単発のフラッシュではなく、スペイン式固定役と浮き役（パル/インパル）理論で「固定と浮き」を作る
4. **メンタル安定化**：接戦終盤で崩れる伝統的弱点を、シミュレーション練習で克服
5. **若手→経験者の橋渡し**：U-21世代に欧州の戦術概念を早期インストール（2020s前半に効果が出始めた）

### じゃんけん（エジプト対策）
- 規律ある6-0 → 6-0の3原則の「完成前」を突く（圧縮中の逆サイド展開等）
- スペイン式ポスト攻撃 → ポストへのパスコース封じが基本
- 長身GK → 下半身の低いシュートが入りやすい
- フィジカル勝負は不利 → 接触対決を避け、速さと位置取りで勝負
- メンタル克服中（伝統弱点） → 接戦終盤のプレッシャーで揺さぶる余地は残る

## 【左利き右バックのグローバル戦術】

> **メイン辞書：`09_individual_differences.md`「左利き右バックの構造的優位」**
> このセクションは「グローバル戦術視点」の補足（各国の育成傾向・DF対策）。
> 個人差・戦術的応用の詳細は09を参照。

### なぜ右バックは左利きが有利か（物理的理由）
```
右バックは右サイドのスペースからシュート/パスを出す
↓
右利き：体を半身に開いてシュート → 角度が狭い
左利き：体が自然にゴール正面を向く → 角度が広い・パワーが乗る

つまり「右バック × 左利き」は構造的優位
逆に「左バック × 右利き」も同じ理由で構造的優位
```

### 各国の左利き育成傾向
| 国 | 左利き活用度 | 戦術への影響 |
|---|---|---|
| フランス | 高（伝統的に育成） | 右バックの中距離・カットインに左利き定石 |
| セルビア・クロアチア | 高（旧ユーゴ伝統） | バック（ベック）の左利き輩出多数 |
| スペイン | 中（ポスト中心） | 左利きポストの伝統 |
| デンマーク・ドイツ | 中 | システムの中で活用 |
| 日本 | 低（一般的でない） | **左利き育成の意識的取り組みが課題** |

### 左利き右バックへの対策（DF側）
- **右ブロックDF**：シュートコースを左側（ファーサイド）から塞ぐ
- **山側／谷側の選択**：左利きには通常と逆側（左側）を山にする
- **アングルカット**：左利きが好む「正面シュート」のコースをDFの体で塞ぐ

### 自チームに左利きがいる場合
- 右バック or 左ウィングに配置するのが構造的最適
- 「左利きはサウスポーシュート」と相手が誤認する場合がある → 通常の右肩シュートとは反対の体勢になるためGKの先読みが狂う

## 【国別の調査から引き出した見方3つ】

> 番号（13〜15）は古い通し番号の名残り。

```
【原則13：構造的知識循環】
小規模集団ほど知識が速く深く循環する
→ アイスランド：レイキャビク周辺の密集した小クラブ群が全指導者の「共同知識プール」を形成
→ チーム内：選手全員が戦術を共有することで判断速度が最大化する（合言葉で全員が同じ動きを思い浮かべる）
→ 応用：チームが小さい≠弱い。知識の循環速度で補える

【原則14：数的優位の条件付き有効性】
数的有利は「自チームの強みと適合するときのみ」有効
→ あえて5on5を選ぶ例：6on5の「遅い整った攻撃」より5on5の「速いトランジション」を優先
→ 強みを活かせない数的優位は優位ではない
→ 応用：ファウルで得た6on5も、チームの実力・スタイルに合わなければ使わない選択がある

【原則15：予測の予測を予測するスパイラル】
GKの予測精度が上がるほど「予測を外す技術」の価値も上がる
→ エリートGKはボールリリースの193ms「前」から動き始めると言われる〔未確認〕
→ 早打ちはその「先取り予測」を逆用する
→ GKが進化するほど、早打ちの価値も比例して上がる（軍拡競争）
→ 応用：相手GKが上手いほど「GKが動く前に打つ」ことの意味が大きくなる
```
