# 兄弟社ホーム：入口を1つにする — 2026-11-20

オーナー指示（2026-11-20）：「メンタルアプリを『兄弟社ホーム』のような名前のアプリにして、入口を統一」。

## 決めたこと

- **別のアプリは作らない**。このアプリ（前のメンタルアプリ）の名前を「兄弟社ホーム」に変えて、入口にする。
  別に作ると、選手は新しいアイコンを入れることになる。iPhoneでは、ホーム画面のアイコンごとに保存場所が別なので、
  新しいアイコンの中で開いたこのアプリは登録し直しになり、前の記録が見えなくなる（移す仕組みは無い）。
- **住所は変えない**（…/handball-mental/）。入っているアイコン・登録・記録はそのまま使える。
  iPhoneのアイコンの下の名前は、入れ直すまで前のまま（MENTAL）。入れ直しは頼まない（保存場所が変わるため）。

## 作り

- 名前：`manifest.json`・題・最初の画面の見出しを「兄弟社ホーム」に。
- ホームの頭に「入口」の段（辞書・振り返り（LAB）／マイ統計）。
- **LAB（handball-system）を、このアプリの住所の下にも置く**（`lab/` フォルダ）。LAB は置き場所を選ばない作り
  （ビルドが相対の住所）なので、LAB のビルド結果（dist）をそのまま `lab/` に写すだけ。
  このアプリの中から LAB を開くと `…/handball-mental/lab/` になり、同じ画面のまま移る。
  iPhoneのアイコンから使っていても、このアプリと同じ保存場所で LAB が動く。
- `sw.js`（裏方）は `./lab/` の下を扱わない（v7）。扱うと、電波が悪い初回に LAB の住所でこのアプリの画面を返してしまう。
  LAB は自分の裏方を `lab/` の下に持つ。
- `.nojekyll` を置いた。GitHub Pages が `lab/dictionary/*.md` を別の形に作りかえないようにするため。
- LAB 側：同じ保存場所にこのアプリの控え（`mental_link_pin_cache`）があり、押した名前の持ち主と同じなら、
  PINを打たずに「つなぐ」1回でつなげる（比べるのは今までどおりデータベースの決まり）。押すまではつながない。
- 前からの LAB の住所（…/handball-system/）は消さない。そこを開いた人には「入口が変わった」知らせを出す。
  iPhoneで LAB のアイコンに記録をためている人だけ、「データの書き出し → このアプリの中の LAB で取り込み」で移す。

## LAB を更新するときの手順（忘れると2つの住所で中身がずれる）

1. handball-system を main に反映する（今までどおり）。
2. その同じコミットで `npm run build` した `dist/` を、このリポジトリの `lab/` に丸ごと写す
   （`rm -rf lab && cp -r <handball-system>/dist lab`）。
3. このリポジトリを main に反映する。

## 確かめ

- 手元で、2つの住所をそのままの形で並べて動かした（外への通信は止めた）：
  入口 → LAB（同じ画面のまま）→ 戻る／同じ保存場所で記録が見える／前の住所の知らせ。
- 本物の iPhone（ホーム画面のアイコン）では確かめていない。全員に知らせる前に1台で確かめる。
